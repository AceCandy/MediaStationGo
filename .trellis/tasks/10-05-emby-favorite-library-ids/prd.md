# 收藏媒体库归属与短剧分类

## 目标与授权
用户已批准在现有接口新增 LibraryIds，并明确旧接口缺少字段时保持原显示，新接口可区分红果短剧。前序手机需求还包括收藏标题栏对齐和轻量加载动效。

## 范围与验收
- 收藏 Movie/Series 返回当前用户可见的真实所属库 ID 数组；多库/合集取去重并集，ParentId 语义不变。
- Views 增加 LibraryType，保留原 CollectionType，供 App 用明确的 hongguo 库类型匹配，不猜名称或条目 ID。
- 手机新增可点击的收藏短剧栏目及网格；仅 Series 且 LibraryIds 命中红果库时分类，缺失/null/空/未知归属及库信息不可用时仍显示普通剧，不丢收藏。
- 本地排序与分页游标契约不变；排序不增加网络请求。
- 修正共享排序入口偏上；收藏加载和列表重排使用已有动画刻度，支持关闭动画。
- 服务端真实 PostgreSQL 回归、客户端字段解析与 UI 渲染回归通过；未覆盖的线上/真机验证明确列出。

## 边界
不改数据库结构、收藏写入、播放或 TV/桌面布局。不部署、提交或推送。已有并行工作不纳入改动。
