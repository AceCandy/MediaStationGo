# 设计

用户已批准整季替代后台单集请求；以下为当前执行方案。

- 批量入口用 context 持有 32 季/16 MiB 原始响应上限的缓存，按来源、凭据、剧 ID、季号隔离；不跨执行复用。
- 优先中文整季；文字不足时查询剧 original_language，再请求一次该语言整季，仅按相同集 ID/集号补文字。
- 从季 episodes 拆分单集 JSON，保留未知字段；没有目标集时记录缺集复查，不自动请求单集。
- 图片使用集自身 still_path，保存、选图和逐集检查点不变。
- 相同季并发合并，等待可取消；失败不缓存。手动刷新和改 ID 不启用批量上下文。
- 快照写入使用原子冲突条件：同 ID 的季拆分响应不能覆盖已有扩展快照；改 ID 和完整单集刷新正常替换。
- PersonRepository 统一拒绝集级写入；批量读取将集映射到所属季并按请求 metadata ID 投影，Web 和 Emby 无需重复映射。
- 启动迁移仅 DELETE 集级 metadata_credits，保留其他关联、人物、头像、来源快照；不直接执行生产清理。
