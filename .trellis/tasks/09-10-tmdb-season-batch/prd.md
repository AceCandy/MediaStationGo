# 同季 TMDb 请求复用与完整快照批量获取

## Goal

后台复用整季信息，中文不足时仅补原始语言；集演职员统一引用所属季。

## Requirements

- 批量目录、季集复查、快照回填及图片修复共用同季响应，减少 HTTP 往返。
- 保留同一 TMDb 集 ID 已有的完整快照；无历史快照时保存整季拆出的集对象。单集后台不额外请求外部标识、翻译、演职员、视频。
- 保留图片下载、选图保护、失败重试、逐集检查点和业务冷却。
- 手动单集刷新仍获取完整单集数据，但不写集级演职员关联。
- Web/Emby 集演职员使用所属季；停止集级关联写入，迁移只清理集级关联，不删除人物、头像或快照。

## Acceptance Criteria

- [x] 同季中文数据复用，一次缓存填充缺文字时最多追加一次原始语言整季请求（剧语言查询、网络重试除外）；不自动请求单集。
- [x] 请求复用只属于当前执行，并发等待可取消且内存有界。
- [x] 重点测试覆盖请求减少、快照保护、缺集复查、图片保存重试，以及季级演职员读取和迁移边界。
