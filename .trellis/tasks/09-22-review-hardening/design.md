# Design

- 在现有 active-user 中间件刷新当前角色/等级，管理与 API-config 组复用。用户与刷新令牌添加默认 0 的认证版本，JWT 携带相同版本；密码更新事务递增版本并撤销 refresh。旧版本 0 会话在改密前兼容，改密后需重新登录；刷新使用捕获的用户版本，避免并发改密生成有效的旧会话。
- 共享 move 实现使用平台原子不覆盖 rename；不支持时安全复制/独占目标，保持同盘性能和跨盘语义。目录复制先独占创建目标，避免失败清理他人的目录。数据库更新失败回滚本次转移；重分类复用恢复逻辑。
- 前端以不持久化的会话代次隔离 refresh 和 API 重试，旧请求不得换用新账号凭据。媒体库 effect/分页传 AbortSignal；带 signal 的请求独立于现有无 signal 去重。
- 调度器统一持有服务生命周期取消及 wait group，普通/补充任务共用；关闭先停止调度，再释放依赖资源。
- CI 使用临时 PostgreSQL service 和隔离 schema；本地使用独立临时 PostgreSQL 实例，结束关闭并移除临时产物。

## Compatibility and rollback

HTTP 形状、token carrier 和媒体排序不变。密码修改后的会话撤销是有意修复。新增版本列由现有 AutoMigrate 管理；回滚应用会失去版本撤销保障，因此修复回滚需评估已撤销令牌。代码按认证、文件、前端、调度、CI 可独立审查。
