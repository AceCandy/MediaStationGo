# Implementation

1. 认证与密码撤销 → 当前身份、旧令牌、改密事务和登录测试。
2. 原子移动与数据库失败补偿 → 并发目标、目录/链接、故障注入测试。
3. 前端会话和请求取消 → Node 回归、现有剧集加载检查。
4. 调度关闭与重复调用 → 请求取消保持、关闭取消/join/幂等测试。
5. PostgreSQL CI 与必要规范同步 → 全部 Go 测试、vet、前端 lint/type/build。
6. 独立只读复核 → 主代理修正、定向重测、关闭临时数据库并清理产物。

所有代码由主代理修改，子代理仅探索与独立复核。无需推送或部署。

7. 剩余数据库回归：先消除 panic，再按模块修复共用根因与陈旧夹具；定向验证后运行真实 PostgreSQL 全量测试并独立复核。
