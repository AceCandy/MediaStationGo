# 设计

## 边界
修改普通媒体读取和编辑链路、任务定义/调度、整理入口、相关测试和规范。
保留独立 NFO/红果/黄果存储与扫描优化，不改变播放身份。

## 读取方向
来源数据是本地资料中心，不在页面读取时发起远端请求。
统一来源合并规则，详情与查询字段共享；作品候选分页先于完整资料装载。
统一使用只读来源投影；依赖迁移完成后删除重复存储，不保留历史兼容回退。
人物/图片不是全部冗余：来源资产与翻译结果仍需持久化。

## 迁移与回滚
不在开发中修改用户数据库。用户确认旧人工值不保留，直接切换。
整理入口先退出注册和调度，不连带删除其他流程使用的文件操作基础能力。
搜索与缓存更新必须具有失败重试，不能随旧补缺消费者一起丢弃。

只读 metadata_presentations 视图保留身份列、来源组合字段和来源图片资产。详情、查询排序和搜索文档共用它；写入仍走身份表。来源变更队列只维护搜索索引与缓存，不再复制资料。

## 补全任务收拢
移除 catalog_hydration_jobs 调度及 people_backfill metadata 候选；扫描仍同步建立所需季集绑定。作品来源维护复用电影/剧/季/集独立任务，新增 TMDb 演职员补全，来源 payload 有效 cast/crew 数组（含空数组）作为完成证据，独立下次尝试时间防止失败阻塞分页。共享来源 Fetch 的请求预算/租约/退避，图片走现有来源图片 worker。旧任务 HTTP 和定义直接退休，不留转发别名。
