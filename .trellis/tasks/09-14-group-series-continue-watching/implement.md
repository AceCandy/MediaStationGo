# 实施计划

1. 定位三个继续观看入口的完整查询与分页路径，确定可复用的最小剧集分组规则。
   - 验证：分组发生在分页前，完整历史调用不进入该规则。
2. 增加后端继续观看聚合，并接入原生 Continue、Emby Resume 与 `IsResumable`。
   - 验证：同剧多集只保留最新未完成集；电影、可见性和版本选择不变。
3. 对红果 Resume 使用其源作品身份聚合，不跨目录合并。
   - 验证：同一红果作品多集一条，不同作品及本地同名作品各自保留。
4. 同步 Emby 管理员接口目录的行为说明；前端首页保持消费现有 DTO，不增加前端去重。
   - 验证：接口目录描述与后端实际契约一致。
5. 增加最小回归测试并独立复核改动。
   - 验证：先运行相关 Go 测试与 `git diff --check`；不默认执行全量 Go 测试或前端全量构建。

## Rollback Points

- 无数据库迁移；可按后端聚合、红果适配、目录说明和测试分别回滚。
- 不修改现有未提交的红果发现页及日志分类工作。
