# 统一红果媒体库剧集展示

## Goal

复用普通剧集卡片与详情，按官方季号聚合，以第一季资料为整剧主体并沿用缺失字段规则

## Confirmed requirements

- 用户已在连续讨论中确认，并以“做吧”授权实施：红果聚合后与普通剧集共用展示，缺失字段沿用原规则。
- 官方合集只显示一张整剧卡片，第一季资料作为整剧主体；未收录第一季时沿用已收录最早季。
- 各季按官方季号展示自身资料和当前库可播放分集；同集不同文件仍为版本。
- 收藏、观看历史和续播保留红果来源身份及用户/媒体库权限。
- 保留旧 hongguo_id 链接和红果电影的可访问性；资料展示不依赖发现权限。

## Acceptance Criteria

- [x] 红果复用 MediaCard、LibrarySeriesDetailSection 及既有季集/文件详情组件。
- [x] 第一季标题、海报、简介、评分、标签、演职员一致；其它季能切换，缺失字段不伪造。
- [x] 分页及集数先按当前库和可见性过滤，版本不重复计集；无串库/串用户。
- [x] 版本、收藏、历史、跨季继续观看与旧链接可用，普通/NFO 定向回归通过。
- [x] 不向红果显示无法支持的 TMDb 刷新/旧元数据编辑入口。
- [x] Web lint/build、定向 Go 测试及浏览器回归通过；移动/桌面、明暗主题无溢出。

## Out of scope

采集与下载、补造分集资料、数据迁移、播放协议、发现页改版、同名推断聚合。
