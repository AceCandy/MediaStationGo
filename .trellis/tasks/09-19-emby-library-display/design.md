# Emby 媒体库展示设计

## 配置与数据流

复用 SettingRepository，将有序条目列表存入单个系统设置键 `emby.library_display`。每项包含稳定媒体库 ID 和隐藏状态，数组位置代表展示顺序；一次写入保证排序、显隐同时保存，不新增表或依赖。

弹窗加载媒体库与已保存设置，合并为本地草稿。保存通过管理员接口提交；服务端验证 JSON 结构、重复 ID 和当前媒体库 ID，保存失败不关闭弹窗。实现时优先复用现有设置 API，并为该设置键增加专用验证，避免任意字符串进入读取路径。

Emby 读取端共用一处排序与入口过滤逻辑，覆盖 Views 和 VirtualFolders；根目录 Items 已复用 Views。现有访问权限照常生效。配置读取错误应返回错误，不以默认全显示掩盖故障。

## 兼容与边界

- 无配置保持现有顺序；配置之外的新库按原顺序追加并默认显示；已删除 ID 在读取时忽略。
- 不改变 library ID、封面、媒体权限、Web 列表或搜索播放行为。
- 不利用库的 Enabled 字段表达展示隐藏，避免混入扫描或访问语义。
- 后续虚拟库接入时再根据实际需求扩展展示条目，不提前搭建注册框架。
- 某些客户端自行排序或缓存库列表，服务端只能保证接口输出；真实客户端兼容需要实际连接验证。

## UI

沿用现有弹窗和按钮风格，拖拽优先复用已安装 framer-motion，配套上下移动按钮保证键盘与触屏操作。列表包含库名称、排序控制和显隐开关，底部取消、保存，加载与保存失败可恢复。

## 改动边界与回滚

预计触及管理页入口、新弹窗、前端 API、设置写入验证、Emby 展示服务、VirtualFolders 和 API 目录说明及针对性测试。保留工作树已有无关修改。配置独立保存，可恢复默认显示；回滚代码后既有媒体库数据不受影响。
