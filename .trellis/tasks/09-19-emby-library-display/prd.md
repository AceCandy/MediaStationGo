# Emby 媒体库展示设置

## 目标

管理员在媒体库页面统一设置 Emby 媒体库入口的显示顺序与显隐，对所有 Emby 用户生效。

## 已确认事实

- 用户已明确由管理员设置。
- 管理入口位于 `web/src/pages/AdminLibraryPanel.tsx:22`，现有新建按钮可作为布局参照。
- Emby 首页由 `internal/service/emby_system.go:129` 的 Views 生成，根目录 Items 复用 Views（`internal/service/emby_compat.go:169`）。
- VirtualFolders 独立枚举媒体库（`internal/handler/emby_views_handlers.go:27`）。
- 现有系统设置支持数据库持久化（`internal/repository/setting_repository.go:27`），管理接口已有管理员权限保护（`internal/handler/routes_admin.go:15`）。

## 需求与范围

- R1：在新建媒体库旁新增“Emby 媒体库展示”按钮，仅管理员可操作。
- R2：弹窗展示媒体库名称、拖拽手柄、显隐开关；支持拖拽排序，并提供键盘可操作的上下移动方式。保存统一提交，取消不写入。
- R3：配置持久化到服务端，对所有 Emby 用户的媒体库入口生效；仍按原有用户权限过滤。
- R4：本次按展示设置处理隐藏：隐藏 Emby 媒体库入口，不修改媒体文件、扫描状态、Web 媒体库或现有搜索、播放权限。
- R5：未配置时保持原行为；新建库默认显示并追加，已删除库不再展示；允许全部隐藏且可在弹窗重新开启。
- R6：后续榜单虚拟库作为后续需求记录，本次不创建虚拟库、榜单数据或通用扩展框架。

## 验收标准

- [x] 排序和显隐保存后保留，已验证新服务实例读取；取消后保持旧配置。
- [x] Views、根目录 Items 与 VirtualFolders 返回一致的排序和显隐结果，数量准确。
- [x] 普通用户不能修改配置，管理员配置不能绕过原有用户访问限制。
- [x] 未配置、新增、删除、全部隐藏、非法提交和保存失败均有明确行为。
- [x] 弹窗在桌面和窄屏可操作，提供可访问名称与键盘操作。
- [x] 相关 Go 测试、前端 lint/build 和独立差异复核完成；真实客户端与实际进程重启未实测。

## 已确认的方案边界

用户已确认方案并批准实施。隐藏仅针对 Emby 媒体库入口，不禁止搜索或播放。
