# 红果弹幕实时合并与 App 参数配置

## Goal

播放器请求红果当前集弹幕时，返回本次实时获取与历史积累的去重合集；管理员可在已有 Web「外部 API」页面配置可选 App 参数。新功能不得改变历史媒体、收藏、观看和下载行为。

## Background

- 2026-09-30：用户批准创建任务并规划实现，新增关注点是独立表和新逻辑对历史功能的影响。
- 匿名实测存在稳定字符串 `comment_id`、毫秒播放位置和创建时间，但没有可靠更新时间/版本号；完整走完时间窗口仍只有少量返回。登录后的完整性尚未验证。
- 现有弹幕出口为空占位：`internal/handler/emby_static.go:162`；已有认证路由：`internal/handler/emby_routes.go:189`。
- 已有源作品＋集号身份：`internal/model/hongguo.go:65`；可直接限定目标分集的权限范围：`internal/service/emby_hongguo.go:55`。
- 设置保存已有 provider 隔离和加密能力：`internal/service/api_config.go:171`；Web 表单位于 `web/src/components/APIConfigsPanel.tsx:165`。

## Requirements

- R1：在现有 Web「外部 API」中添加红果弹幕配置，支持 Cookie、x-tt-token、User-Agent、device_id、iid 和高级 App 公共查询参数。全部可选；凭据及设备标识加密保存、不回显、不进入日志；普通保存保留未填写的已存值，提供明确清除入口。配置为空显示匿名模式，不将其视为不可用。
- R2：仅播放器请求当前集弹幕时实时获取，不预取、不扫描整季、不注册周期采集任务。
- R3：新增独立红果弹幕表，以源作品和集号归属；红果视频 ID 只用于内部请求解析，不作为业务归属键。同一合集不同作品的同集号互不影响；历史弹幕不跟随资料清理而消失。
- R4：实时结果与本地历史按单条弹幕 ID 合并、去重、按播放时间排序，并将合并结果返回播放器。
- R5：仅新增未知弹幕，异步保存；源站少返回或删除的旧弹幕不从本地移除。获取失败时返回已有数据。
- R6：现有 raw 路由为可见红果分集返回 Emby 弹幕插件兼容 XML；维持鉴权和媒体可见性。普通媒体/NFO 保持现有空响应，不增加插件搜索、刷新、字幕或 JSON 管理接口。
- R7：不得改变普通媒体/NFO、红果收藏、已观看、播放记录、下载和既有外部 API 配置行为；不得修改或回填历史业务数据。

## Acceptance Criteria

- [x] AC1/R1：配置为空可保存并匿名尝试；已配置敏感值不回显，普通保存不误清空，明确清除后恢复匿名行为；下一次弹幕请求观察最新配置，关闭该配置停止上游请求但保留可见集的历史弹幕。
- [x] AC2/R2：弹幕请求只读取/拉取目标集，不扫描作品下其他集；设置保存不触发采集。
- [x] AC3/R3：同一合集不同源作品的相同集号互不串数据；源视频 ID 更新不丢失本集历史弹幕。
- [x] AC4/R4-R5：已有 100 条，本次返回其中 95 条和新增 20 条，响应和最终持久化均为 120 条；重复请求幂等且按时间排序。相同文本、相同时间但不同弹幕 ID 不误合并。
- [x] AC5/R5：超时、业务错误、解析失败、成功但为空均保留历史弹幕；异步写入失败不影响本次已合并的响应。
- [x] AC6/R6：Emby 输出协议、转义和时间单位正确；未认证和不可见媒体不能读取或触发获取。
- [x] AC7/R7：新增迁移重复执行安全且不引入旧表数据转换；非红果弹幕请求及旧设置/收藏/观看/播放/下载相关回归保持不变。
- [x] AC8/R2/R5/R7：请求有截止时间且并发有界，异步保存纳入服务关闭等待；不调用视频下载、不保存源签名地址、不在播放主链路启动采集。

上述验收通过自动化测试和独立复核；核验范围见 `research/implementation-check.md`，不包含下述登录态、实机和生产验收。

## Out of Scope

- 自动登录、账号注册、设备注册、观看/曝光上报和自动获取用户凭据。
- 扫全库、预取整季、定时采集、全量弹幕保证、按整集数量覆盖或删除历史。
- 新播放器、下载行为改变、历史数据重算、生产部署、提交和归档。

## Risks and Deferred Acceptance

- 登录参数只提供验证与使用能力，不保证源站返回全部弹幕；实际账号对照仍需用户在本地自行配置。
- XML 协议可用源码和自动化测试核对，YAMBy 实机是否主动调用该出口、是否正确显示仍需设备验收。
- 异步保存遇到数据库失败或进程突然终止可能未落盘，已返回的数据不应被撤回；后续请求可再次增量入库。
- 实现与独立复核已完成；保持未提交、未归档状态。
