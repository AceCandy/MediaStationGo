# TMDb 资料中心实施记录

用户已确认实施并要求提交归档。代码位于 main，与依赖的图片目录任务一并提交；用户已自行重启，实际运行及生产迁移结果尚未核验。

## 已实现

- 七张来源表及 PostgreSQL 层级约束/索引，作品和季集父链、公共人物身份复用。
- 原始组件/语言和来源投影分离；作品演职员、人物履历独立同步；完整履历校验后事务替换，多角色保留、按作品分页。
- TMDbProvider JSON 入口统一进入中心；搜索/榜单只登记摘要，不再自动排本地完整目录补全；既有显式目录补全继续保留。
- 来源新写入走中心，旧快照 wrapper 通过兼容 relation 读；基本资料和扩展分别保留。合并本地作品前保全旧 TMDb 来源，失败回滚。
- 离线迁入旧快照、无快照绑定身份、人物及同源图片引用；保留成功时间与公共人物 ID，异常 ID 可见，不删除旧记录。
- 基础/扩展 TTL、HTTP 真实尝试预算、同请求合并、取消隔离、租约 token、持久失败退避/429 冷却；旧 API 配置任务交接，较旧响应正常释放租约。
- 通用任务中的 TMDb 资料刷新和历史迁移；周期默认关闭、每小时默认100请求，可配1–1000；单集扩展按需，未加载人物履历不自动抓取。
- 显式补全与周期待办分开：周期预算耗尽不会进入3秒显式 worker 偷跑；普通用户最多50个未完成ensure。
- 来源图片内部路由、资料目录与旁置缩略图复用；人物来源图片引用可跨重启复用；失败保留旧图/no-store，单图手动重试独立。
- 资料中心豆瓣/TMDb切换，电影/电视剧/人物列表，资料级别/刷新状态/关键词分页；剧→季→集弹窗、人物反向作品/多角色聚合筛选、层级与来源链接、来源JSON和刷新状态。
- 发现弹窗保留本地投影；自动改本地改为显式“刷新本地资料”；无本地作品时只读来源并受控补缺。
