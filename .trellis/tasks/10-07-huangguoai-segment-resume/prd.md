# 黄果下载失败后复用成功分片

## Goal

保存可校验分片进度，跨任务重试安全复用，保留完整媒体校验

## Requirements

- 用户已确认清单一致、缓存完整才复用的方案并授权实施。
- 持久化成功分片完成记录；半截文件不能复用。
- 每次重试重新解析清单、读取密钥和初始化资源；身份或上下文变化重新下载。
- 保持租约独立目录，旧目录只读，新旧任务不能共同写同一文件。
- 传输失败可以保留完成分片；合并或完整媒体校验失败清理缓存。
- 完成记录只含摘要和大小，不能持久化媒体URL、签名或密钥原文。

## Acceptance Criteria

- [ ] 跨任务重试仅请求缺失分片，旧目录不被写入。
- [ ] 清单、密钥或初始化数据变化不复用缓存。
- [ ] 截断、同长度损坏、缺失记录、软链接不能复用。
- [ ] 取消/旧租约重叠不产生半成品发布，计入总量和进度。
- [ ] 独立完整解码、时长核对和无覆盖发布仍生效。
