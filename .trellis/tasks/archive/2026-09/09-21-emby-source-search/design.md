# 设计

普通资料保留现有索引；红果复用 HTTP 后端和索引重建协调器，使用普通 alias 加 `_hongguo` 的独立 alias。索引只保存逻辑作品投影，不创建共享 metadata 记录。合集按官方身份建立一个文档。

红果索引保存资料，不保存易变文件权限。查询先从数据库取得可见、已有文件的逻辑身份，在 OpenSearch 候选截断前限制 ID，返回后用数据库重新验证与统一排序。资料和合集修改在提交后刷新旧、新逻辑身份；删除同样刷新受影响合集。失败标记阻止使用已知过期索引，后续重建恢复。

抽取现有重建协调器以供两种来源使用，保留临时索引、dirty 追补、原子 alias 切换和取消语义。启动预热分别执行两个来源，使用现有批量/间隔配置。

普通资料搜索已有 NFO 数据库候选合并；Emby 使用该结果加红果候选，统一排序分页后才加载当前页详情。层级及复杂播放筛选保留现有数据库路径。

回滚仅撤销本任务代码，旧普通索引兼容；新增红果 alias 与旧索引隔离。不改数据库结构。
