# Emby 分来源搜索与红果独立索引

## Goal

普通库与红果独立检索，合并 NFO 候选并统一分页，修复全局搜索绕过 OpenSearch 的超时路径

## Requirements

- 普通资料与红果使用独立 OpenSearch 索引，共用现有连接配置。
- Emby 全局作品搜索合并各来源候选后统一排序分页，NFO 存在不能绕过普通资料搜索后端。
- NFO 保留数据库搜索；只有可见且有文件的作品可返回。
- 保留现有层级、人物、收藏、播放状态及特殊类型搜索语义；复杂状态查询允许使用数据库。
- 红果索引支持启动重建、资料/合集变更及删除同步，失败时回退数据库。

## Acceptance Criteria

- [x] 混合三来源时普通库和红果后端均被调用，统一分页无重复。
- [x] 无文件、隐藏库、锁定用户的作品不进入搜索结果。
- [x] 索引更新/重建/删除及故障回退有可运行测试。
- [x] 既有搜索、NFO、红果和索引测试通过，完成独立复核。

## Notes

- 用户已在分来源索引和聚合方案说明后明确批准实施。不涉及生产重启、配置修改或提交他人改动。
- 代码验收完成；现有服务未重启，播放器端实际请求仍需部署后复测。红果索引随启动预热，未就绪时回退数据库。
