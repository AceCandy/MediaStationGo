# 补全电视剧角色翻译上下文

## Goal

让电视剧角色翻译获得可识别作品的上下文，避免只把“第 2 季”或单集标题发送给 AI，并让任务日志展示同一上下文。

## Background

- 当前角色翻译直接使用角色关系所挂元数据的标题；季级关系只得到季标题，集级关系只得到单集标题。
- 角色翻译缓存已按季隔离，元数据模型已有 `Parent`、`ParentID` 和 `SeasonNum`，无需数据库迁移。

## Requirements

- 电视剧根节点上的角色继续使用电视剧标题。
- 季节点上的角色使用“电视剧标题 / 季标题”作为 AI 上下文。
- 集节点上的角色回溯所属季和电视剧，使用“电视剧标题 / 季标题”作为 AI 上下文，不包含单集标题。
- 任务详情复用发送给 AI 的标题，显示如 `[电视剧: 剧名 / 第 2 季]`。
- 父级数据缺失时保留当前元数据标题作为降级结果。
- 电影与人物姓名翻译行为保持不变。

## Acceptance Criteria

- [x] 季级角色的 `AITranslationContext.Title` 包含电视剧标题和季标题。
- [x] 同一季不同单集的相同角色仍合并为一个翻译组，且上下文包含所属电视剧和季标题。
- [x] 电视剧角色任务详情包含电视剧标题和季标题。
- [x] 电影角色任务详情及现有缓存键格式保持不变。
- [x] 相关 Go 单元测试通过。

## Out of Scope

- 不清空翻译缓存，不自动重翻已经写回中文的历史角色。
- 不新增数据库字段、迁移或 AI JSON 字段。
- 不修改人物姓名翻译、电影翻译或其他元数据展示。

## Technical Notes

- 复用现有 `AITranslationContext.Title` 和 `OriginalTitle`，避免扩大 AI 请求契约。
- 查询仅为当前分页角色预加载最多两级父元数据。
