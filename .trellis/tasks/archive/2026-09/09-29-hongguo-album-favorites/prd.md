# 红果媒体库按合集收藏

## Goal

红果媒体库按整剧／合集展示，收藏也应保存该展示主体的身份；Web 与 Emby 使用相同收藏状态，并避免收藏请求扫描全库。

## Background

- 现有 Web 整剧收藏通过 `HongGuoSeriesFavorite` 分别写入可见源作品；Emby `hongGuoContainerMutation` 先展开全库层级，实际收藏请求的定位查询耗时约 19 秒，随后请求取消。
- 用户已明确确认：收藏对象应是媒体库展示的合集，可以直接记录合集 ID；发现页不需要新增收藏。

## Requirements

- R1：合集收藏直接保存用户与合集身份，不展开并复制各季的收藏；独立作品保留作品级收藏。
- R2：Web、Emby 的收藏／取消、详情状态、收藏筛选及“我的收藏”保持一致。合集新增可见成员后保持收藏。
- R3：已有收藏在升级后保留；取消合集收藏后不能被旧成员记录重新显示为已收藏。
- R4：保留用户隔离、媒体库／档案可见性、电影与整剧可收藏而季／单集不可收藏的边界。
- R5：收藏写入仅检查目标的必要可见性，不能为了定位单个合集加载全库文件、封面或播放状态。
- R6：全局收藏列表的准确总数及分页从用户收藏身份限定候选，不汇总无关红果合集；保持原权限、排序和总数语义。

## Acceptance Criteria

- [x] 收藏合集仅保存一个用户／合集关系；重复收藏、取消收藏幂等。
- [x] 已收藏合集新加入一季后，Web 与 Emby 仍展示同一收藏状态。
- [x] 收藏筛选、详情与用户收藏页结果一致，受限用户看不到不可见合集。
- [x] 旧收藏兼容或迁移、取消后的状态、独立作品、用户隔离均有 PostgreSQL 回归检查。
- [x] 定向性能检查证实收藏查询范围被目标身份约束；独立复核完成。
- [x] 全局 Series 收藏 + DateLastContentAdded + 准确总数的稀疏收藏计划回归通过，无无关作品扫描或 JIT 编译。

## Out of Scope

- 发现页收藏、季／单集收藏、播放器 UI 调整及无关播放状态语义。
