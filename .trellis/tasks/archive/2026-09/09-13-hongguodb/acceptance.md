## 逐项操作

### A01 升级与隔离

1. 备份后启动新版本，确认日志没有迁移错误；再次启动确认幂等。
2. 打开原媒体库，抽查影片、剧集、演员、图片、收藏与播放进度。
3. 确认出现 hongguo_ 独立资料表和两个独立用户表。红果导入不应新增旧 metadata_items/旧人物；公共 media 的红果行 metadata_id 应为空。

自动证据：临时 PG 真实初始化迁移连续两次、旧资料哨兵、事务回滚。未验证生产数据规模下的迁移耗时和锁等待。

### A02 任务体系

任务体系切换现为三个并列标签，选中项紫色高亮；本轮已检查三项切换回调和重复点击当前项不触发切换。实际浏览器的明暗主题、窄屏换行仍待人工核验。

1. 打开 `/admin/tasks?system=hongguo`，只应显示红果发现、刷新、图片任务。
2. 切到公共/现有资料，再浏览器后退、刷新；URL 和显示体系保持一致。
3. 红果视图不出现旧季集复查待办；待匹配链接打开 `/discover?system=hongguo&pending=1`。标签名称应为“红果短剧”。

### A03 导入与刷新

1. 打开 `/discover?system=hongguo`，展开“资料管理”，输入真实上游作品 ID，点“按 ID 导入 / 刷新”。旧 `/hongguo` 会跳转至此。
2. 导入后打开详情，核对完整 ID；重复导入不产生第二部同 ID 作品。
3. 从红果任务中心启动作品发现，日志应显示目录摘要记录；不会逐部请求详情，正式资料目录不应出现只有摘要的占位作品。
4. 启动资料刷新，已发现的新作品陆续进入资料目录并可按 ID 匹配；超过100部待补齐项应继续分批处理。刷新开始后新发现的项留待下次刷新。
5. 重复发现不能覆盖完整详情；24小时内重复常规刷新不重复请求刚成功的旧作品，但指定 ID 刷新仍立即请求。发现遇到失败后重启，从该分类未完成页继续；摘要和页码一起保存。
6. 发现不再每分类只拉20页：持续到有效空页后换下一分类。重复页、网络失败或非空第10000页应明确失败，不冒充全量完成；取消保留进度，再次启动续跑。实际覆盖范围仅限上游公开分类返回的内容。

大于 JavaScript 安全整数的 ID 已有自动往返检查；不需要用户人为修改 ID 制造精度问题。

### A04 资料和图片

1. 将详情标题、简介、标签、演员、评分和更新文案与来源网页比对。
2. 区分“红果上线”与首播日期；缺失字段保持未知，不应补造年份。
3. 运行图片任务后刷新，检查作品海报和 Emby 人物头像；公开响应不包含来源签名 URL。

来源不提供的分集标题/简介不应伪造。人物卡片文案不代表角色名。

### A05 单集分类

1. 导入明确写着全1集且数量一致的作品，预期电影。
2. 导入只更新到第1集、未确认完结的作品，预期剧集。
3. 可访问集数不足不应降低作品总集数。

### A06 文件匹配

1. 新建红果短剧类型媒体库，指向测试目录。
2. 剧集目录示例：`作品名 [hongguo-真实ID]/Season 01/作品名 S01E001.mp4`；STRM 同样命名。
3. 电影示例：`作品名 [hongguo-真实ID]/作品名.mp4`。
4. 扫描后应绑定对应资料；没有资料时进入待匹配，随后导入资料应完成绑定。
5. 重扫不重复入库；不需要 NFO。旧体系手动匹配/编辑不得把红果文件写入旧资料。

目录中“真实ID”必须替换为真实上游字符串。人工聚合后仍使用源 S01Exxx，不要按展示季号重命名。

### A07 Web 与 Emby 播放

1. Web 媒体库打开红果库，点击作品及可见文件版本播放；检查视频、音频、拖动、字幕。
2. Emby 客户端重新加载媒体库，检查电影/剧/季/集、搜索、最近添加和演员。
3. 同一集有多个文件时，检查 MediaSource 版本选择；切换版本仍是同一集的观看状态。
4. 受限账号/锁定档案不可浏览或播放无权限文件。

自动已检查 Range 字节、STRM 302、PlaybackInfo 和身份；真实视频解码、字幕、播放器缓存未用实际设备验证。

### A08 人工聚合

1. 先播放源作品 B 第2集至少20秒，记下进度。
2. 在资料详情编辑聚合：A 指定第1季、B 指定第3季，保存。
3. Web/Emby 应按一个整剧下第1/3季展示，B 第2集进度不变。
4. 调整 B 的展示季号，再解除整个聚合；文件、源 ID、分集身份和进度仍保留。
5. 重复季号或电影成员应拒绝，不部分保存。

### A09 用户数据与统计

1. 账号甲收藏并播放至少20秒，账号乙不应看到甲的收藏/历史。
2. 在“我的”切到红果短剧，检查继续观看、标为已看、清除进度；继续播放从记录位置开始。
3. 管理员打开 `/playback-stats?system=hongguo`，检查账户/日期/库/类型筛选、明细翻页和日/周排名；切回现有体系数据不混合。
4. 同一播放会话重复上报只算一次；手动已看不增加播放次数；清除进度不删除真实事件。
5. 删除测试文件后统计仍保留不可用事件，不提供失效媒体链接。

无可见文件的收藏仍保存，但暂不在“我的”卡片中出现；绑定可见文件后出现。排名按源作品统计，聚合只修改展示名称/季号。

### A10 取消和恢复

1. 运行来源任务后取消，任务应为中断，不应把取消记为作品抓取失败。
2. 作品发现、资料刷新和图片下载可以同时运行并有各自日志，同类任务不能重复启动。点击“取消所有红果任务”或停用来源，三者均应停止。图片任务开始后新采集的图片留待下一轮下载。
3. 对自然出现的网络失败观察失败ID保留；刷新任务到重试时间后继续处理，不阻断其他作品。
4. 正常重启服务，检查业务检查点保留、无重复并发；不要为了验收删除业务表或快照。

### A11 停用与启用

1. 在 `/hongguo` 停用采集；新任务与新绑定停止。
2. 旧资料、文件、收藏和进度仍在，已有可见绑定仍能查询/播放。
3. 停用期间重扫的绑定尝试会报停用并回滚，不替换旧绑定。
4. 重新启用后再扫描/刷新恢复处理。停用不是卸载，不删除来源表或用户状态。

### A12 页面与权限

1. 手机/平板/桌面以及明暗主题检查资料页、任务页、来源库、“我的”、统计和 `/admin/emby/interfaces`。
2. 检查键盘操作、弹窗、分页和错误重试，无控件遮挡或页面横向溢出。
3. 普通账号不应出现导入、聚合编辑、启停、任务管理和统计管理权限；直接访问管理 API 同样拒绝。
4. 播放器接口目录搜索 HongGuo/Persons/Counts，检查筛选、展开与复制反馈。
5. 观看空间仅保留“发现”入口；点击并列“现有资料体系 / 红果短剧”标签，刷新和前进后退应恢复 URL 选择。旧 `/hongguo?id=真实ID&page=2` 应保留参数跳转。
6. 红果列表检查圆角竖海报、更新集数、评分、标题和真实题材标签；图片尚未下载或损坏时显示占位，运行图片任务后刷新目录确认真实海报出现。
7. 关闭普通账号“发现”权限后，发现和旧红果链接均不可进入；已有可见媒体的播放和用户记录接口不受此项额外限制。

浏览器自动检查使用测试响应，只覆盖部分页面、屏宽和主题；不等同于以上全部组合实测。
