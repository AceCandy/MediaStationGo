# HongGuoDB 技术设计

## 边界

- 红果拥有独立的作品、分集、人物、演职员、快照、图片、同步检查点及人工聚合表；使用显式 hongguo_ 表名，避免 ORM 缩写推导差异。
- 作品上游 ID 保持字符串；内部行 ID 使用现有 UUID 基础类型，不作为下载整理时的用户 ID。
- 不修改旧 metadata_items 的语义，不将红果资料投影写入旧表。旧表上的维护触发器不负责红果。
- Media 继续表示物理文件；红果通过独立绑定表关联文件，旧 MetadataID 留空。扫描、刮削、探测需在真实入口区分资料归属，不能只过滤 Web。
- 红果用户状态与资料分开管理，不能通过来源资料外键级联删除；旧用户状态和旧 Emby ID 不迁移。具体公共查询适配随端到端链路落实，不引入不必要的插件框架。
- 媒体库显式选择 `hongguo` 类型；文件 `catalog_source=hongguo`、`metadata_id=NULL`，来源作品匹配提示存 `lookup_catalog_id`。重扫坐标无效时解除旧绑定，保留待匹配文件。
- 用户状态独立 `hongguo_user_states` / `hongguo_playback_events`；作品收藏使用源集号 0，电影进度始终使用源集号 1，避免单集剧确认完结转电影时丢失进度。
- Emby 来源身份为 `hg-work-`、`hg-group-`、`hg-season-`、`hg-episode-` 加内部 UUID；逻辑目录按用户可见的已绑定文件查询生成，不向旧资料表保存替身。

## 来源数据

- HTTP 请求带超时、取消和响应大小限制，仅请求红果固定来源；HTML 中提取 _ROUTER_DATA，再用保留整数精度的 JSON 解码读取。
- 分类列表只批量保存 ID 和摘要到 hongguo_discoveries，并与页码检查点同事务提交；详情用于权威更新。不存在对应正式作品且不在失败队列的发现记录，即为待补齐项，不另存冗余状态。保存经过白名单选择的详情快照，不存请求上下文、相关推荐或评论。
- 发现取消每分类20页批次上限，从各自检查点持续翻到有效空页；空页才归一到首页供下轮巡检。整页都是本轮已见ID时明确报分页异常；第10000页仍非空时保存该页且保留其页码，明确报安全上限，不冒充拉取完整。
- 首次可见时间单独表达为上线时间；不推断跨季关系。全一集电影判断要求原始完结证据，未知状态不猜测。
- 详情成功后在事务中更新作品、集号与演员关系和快照；失败不得部分覆盖成功数据。列表和刷新分页有界、支持取消，未抓到不等于删除。
- 图片在来源独立目录落盘，下载与资料采集状态分离；下载失败可重试，签名地址不进入公开 DTO 或日志。

## 聚合与匹配

- 一个源作品最多属于一个人工聚合，聚合内季号唯一；拒绝单集电影成员。
- 文件始终以 hongguo 源作品 ID 和源季集坐标匹配，聚合只改变呈现季号，不改源作品与集身份。
- 未聚合作品正常作为独立剧和默认第一季呈现。删除聚合只解除关系，不删除资料、文件和用户状态。

## 任务与界面

- 一个任务中心，URL 持久化公共/现有资料/HongGuoDB 归属。任务定义和执行记录带来源归属，专属 kind 与调度键隔离互斥和配置；复用现有日志、取消和历史能力。
- 发现、详情刷新和图片各有独立运行槽，可同时运行，统一取消/停用/关闭。发现不自动触发另外两个任务。刷新先按固定开始时间和每批100条游标消化新作品，再处理本轮开始时到期的50条失败和超过24小时的100条旧资料；指定 ID 刷新不受间隔限制。未补齐摘要不进入正式 Web/Emby 目录。
- 红果短剧资料浏览和详情使用独立 API；分页、搜索、错误和空态均有界，不加载整个资料库。观看空间统一从“发现”进入，以 system=catalog|hongguo 并列标签切换；旧 /hongguo 保留参数重定向。目录路由和作品/分集/聚合 GET 统一受 can_view_discover 控制，媒体、图片和用户状态沿用原权限。
- 海报目录从列表投影批量取得本地 artwork_id 与 tags，不逐卡请求详情，也不凭标题推断官网分类。用户可见名称统一“红果短剧”，内部表名和来源 ID 不变。
- Emby 在统一鉴权、可见性和媒体播放基础上读取红果投影；来源 ID 命名空间避免与旧 ID 冲突。不能返回无文件的可播放条目。

## 兼容与回滚

- 优先新增来源表与可选字段，禁止迁移或移动真实媒体文件。
- 来源停用停止来源任务与新绑定，不删除用户状态和本地文件。破坏性卸载不属于默认升级路径。
- 数据库验证使用独立 PostgreSQL 测试 schema；不在用户生产库试跑导入或清理。
- 每一步的兼容性发现、自动检查结果及未验证限制写入 implement.md 和 acceptance.md，未通过完整链路前不声称完成。
