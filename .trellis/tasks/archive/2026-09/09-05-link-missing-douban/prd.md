# 未关联豆瓣时提供关联入口

## Goal

让用户能在媒体详情页发现并补充缺失的豆瓣关联，同时不改变已有豆瓣关联的访问方式。

## Background

- 当前详情页只有已关联豆瓣的媒体会显示豆瓣图标。
- 已关联时，点击豆瓣图标会直接跳转到对应豆瓣页面；这是需要保留的已有能力。
- 项目已有“编辑元数据”弹窗，其中包含豆瓣 ID 字段及完整保存链路。
- 现有元数据编辑入口及保存接口均仅允许管理员使用。

## Requirements

- 未关联豆瓣时，详情页仍显示豆瓣图标。
- 未关联状态需要明确提示当前没有豆瓣信息，避免用户误以为可以直接访问豆瓣页面。
- 已关联状态的展示和点击跳转行为保持不变。
- 优先复用已有元数据编辑与保存能力，不新增后端接口。
- 所有用户都能看到未关联豆瓣的提示态图标。
- 管理员点击未关联图标后复用已有元数据编辑弹窗，可填写并保存豆瓣 ID；普通用户只能查看提示，不能进入设置。

## Acceptance Criteria

- [x] 已关联豆瓣的媒体继续显示豆瓣图标，点击后直接跳转到原豆瓣页面。
- [x] 未关联豆瓣的媒体也显示豆瓣图标，并能看到“没有豆瓣信息”的提示。
- [x] 管理员点击未关联状态的豆瓣图标后，打开已有元数据编辑弹窗，并可填写和保存豆瓣 ID。
- [x] 保存成功后，该媒体表现为已关联状态，点击图标可跳转到对应豆瓣页面。
- [x] 普通用户可看到未关联提示，但不能由该图标进入设置。

## Out of Scope

- 不自动搜索或自动匹配豆瓣条目。
- 不改变 TMDB 等其他外部信息源的现有行为。
- 不新增仅编辑豆瓣 ID 的专用接口或弹窗。
