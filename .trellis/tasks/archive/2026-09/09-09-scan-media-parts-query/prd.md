# 扫描分段关系查询优化

## 目标
- 分段校正只读取实际使用的媒体字段。
- 局部扫描在数据库内缩小目录候选范围，保留原有路径判断。
- 保持全库、子目录、大小写兼容、特殊路径字符、单文件恢复与标题修正行为。

## 验收
- PostgreSQL 回归测试验证查询返回范围及分段关系。
- 既有 multipart 扫描测试通过。
- 只修改分段校正及其测试，不修改数据库索引或扫描调度。

## 验证结果
- PostgreSQL 17：新增目录范围回归（含全库、根目录、特殊字符、大小写及删除恢复）通过。
- 文件名解析、重复序号、目录大小写分组、剧集身份测试通过。
- 修改前后对照：既有单文件恢复测试的标题大小写断言、根目录测试的 root not found、Emby multipart 测试的 ON CONFLICT 约束错误均已存在，未扩大范围修复。
- 新测试在旧查询上失败（全字段读取、局部目录返回额外记录），在新查询上通过。
- gofmt、git diff --check、逐行独立复核完成。未验证真实媒体库性能或全量测试；全库查询仍遍历所有本地媒体。
