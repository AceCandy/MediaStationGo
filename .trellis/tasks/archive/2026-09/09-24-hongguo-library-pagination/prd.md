# 优化红果媒体库分页查询

## Goal

先筛选有可见文件的红果作品并按合集分页，仅聚合当前页文件，验证空合集与空季号的回退。

## Requirements

- 从当前库和当前权限下存在已绑定 media 的红果作品确定可展示集合；按官方合集去重、计数和分页。
- 只为当前页作品统计本地分集数、文件版本数并选择代表文件。
- 空合集/空季号维持自身独立作品、第 1 季的展示回退；保持已有条目 ID、源 ID、播放状态和深链兼容。
- 保持标题排序、整剧主体取最早已收录季、无海报/无中文标题筛选、多版本去重及电影路由。
- 不写回来源关系，不新增缓存、索引或依赖，不改变其他目录来源。

## Acceptance Criteria

- [x] 隔离 PostgreSQL 测试覆盖合集、独立作品、第一季无文件、重复版本、权限、筛选和空页总数。
- [x] 空关系作品按第 1 季进入列表和详情，legacy 来源链接可用。
- [x] 真实数据库只读对照新旧分页结果，验证代表文件、计数和顺序一致。
- [x] 执行计划确认只为当前页展开并排序文件，记录优化前后耗时。
- [x] 独立复核通过；未启动额外业务服务，临时诊断测试已移除，测试浏览器已关闭。

## Background

首屏接口实测 6.84–8.98 秒。`internal/repository/hongguo_series.go:47` 在分页前聚合约 50.45 万文件行，排序落盘约 126 MB。用户已确认先判断作品文件存在性、分组分页，再补充当前页文件信息的方案，并授权实施。
