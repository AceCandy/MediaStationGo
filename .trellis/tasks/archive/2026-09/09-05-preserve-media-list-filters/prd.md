# 保留媒体列表筛选状态

## Goal

用户从已筛选的媒体库列表进入媒体详情后，点击“返回媒体库”能够回到进入前的筛选结果，无需重新选择筛选项。

## Background

- `LibraryPage` 当前将“无海报”和“无中文名”保存在组件本地状态，离开页面后会丢失。
- 详情页“返回媒体库”当前根据媒体信息重新生成媒体库地址，不包含进入详情前的筛选状态。
- 项目已有通过 URL 查询参数保存页面状态、通过路由来源地址实现返回的模式。

## Requirements

- “无海报”和“无中文名”筛选状态必须反映在媒体库 URL 中；未选择时保持现有无参数行为。
- 从媒体库普通媒体卡片进入详情时，必须携带进入前的完整媒体库地址。
- 详情页点击“返回媒体库”时，优先返回该来源地址；没有来源地址时继续使用现有媒体库返回规则。
- 两个筛选项可单独或同时恢复，并继续与现有剧集查询参数共存。
- 不新增全局状态管理或第三方依赖。

## Out of Scope

- 不保存滚动位置、已加载页数或其他未提出的列表状态。
- 不改变从首页、搜索、收藏等其他入口进入详情后的既有返回行为。
- 不改变媒体筛选 API 与后端逻辑。

## Acceptance Criteria

- [ ] 仅选择“无海报”后进入任意普通媒体详情，再点击“返回媒体库”，仍显示“无海报”筛选结果且筛选控件保持选中。
- [ ] 仅选择“无中文名”时执行同一路径，筛选结果与控件状态保持不变。
- [ ] 同时选择两个筛选项时执行同一路径，两个筛选项都被恢复。
- [ ] 取消筛选会同步移除对应 URL 参数，刷新媒体库页面仍按当前 URL 恢复筛选状态。
- [ ] 没有媒体库来源信息的详情页仍按现有规则返回对应媒体库。
- [ ] 前端 lint 与构建通过，并完成独立代码复核。
