# 豆瓣手动匹配与即时补齐

## Goal

独立豆瓣匹配入口、类型确认与强制绑定，并立即补齐当前作品信息

## Requirements

- 豆瓣按钮直接搜索当前作品名；候选类型由详情确认，不能信任联想接口通用 movie 标签。
- 类型不同应用时弹窗，可取消或强制绑定；应用立即补齐字段、快照和海报。
- 强制只放宽类型限制，不覆盖非空字段/已有海报（保留中文标题优先规则），不改变本地类型、季集结构、文件关系和其他标识。
- 持久化人工确认的实际豆瓣类型，后台只对明确强制绑定使用例外接口。
- 不自动修复历史绑定，不部署、不提交。

## Acceptance Criteria

- [x] 正常应用立即入库；跨类型取消零写入，明确强制后成功。
- [x] 网络/数据库失败保留旧绑定；类型校验由后端执行。
- [x] PostgreSQL 覆盖季集不变、事务回滚、例外持久化与后台冷却。
- [x] Web 类型展示、确认、刷新、lint/build 与交互测试。

## Notes

- 用户已确认完整流程并批准实施和建任务，没有未决产品问题。
