# 修复纯数字豆瓣搜索回退

## Goal

让纯数字片名在对应豆瓣 ID 不存在时继续执行关键词搜索，返回豆瓣已有的正确候选。

## Background

- 裸数字查询当前兼容豆瓣 ID 输入，不应移除该行为。
- 查询 `2046` 时，ID 详情回退接口返回 `200 {"r":"error"}`；详情解析器仍生成标题为空的 `Match`。
- 手动搜索将该非空 `Match` 当作成功结果，跳过 `subject_suggest?q=2046`，上层随后过滤空标题，最终无候选。

## Requirements

- 豆瓣详情响应无法提供非空标题时，不得生成有效 `Match`。
- 裸数字对应有效豆瓣 ID 时，现有 ID 查询行为保持不变。
- 裸数字对应无效豆瓣 ID 时，手动搜索继续回退到关键词候选搜索。
- 修改仅限豆瓣详情解析约束和对应回归测试。

## Acceptance Criteria

- [x] `doubanMatchFromRawJSON` 对无标题详情返回空结果和错误，而不是无标题 `Match`。
- [x] 手动搜索 `2046` 在 ID 请求失败且抽象接口返回 `{"r":"error"}` 后，调用关键词候选搜索并得到豆瓣 ID `1291555`。
- [x] 现有豆瓣候选搜索和 provider ID 解析测试继续通过。

## Out of Scope

- 不取消裸数字作为 provider ID 的兼容行为。
- 不修改豆瓣代理池、请求路由或前端搜索交互。
- 不扩展到其他元数据 provider。

## Risk

- 详情接口若合法响应缺少标题，将被视为不可用；该结果本身无法形成可展示或可持久化的有效媒体匹配。
