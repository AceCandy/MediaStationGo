# Design

## Architecture

2026-09-09 慢 SQL 调整：待办非空搜索使用 matched MATERIALIZED CTE 供 total/page 共用；整剧库使用 scoped/works/page CTE，共用一次关联投影及作品分组，分页后计算代表文件和计数。两者均由总数 LEFT JOIN 页结果，确保越界空页不丢失总数。电影分段规则和空关键字快速路径保留。仍需扫描匹配范围来确定全局排序/精确总数，不承诺恒定耗时。

用户已批准追加 Web 只读列表：在 TasksPage 中针对 tmdb_episode_metadata_recheck 显示待办入口；管理员只读 API 以新待办状态为数据源，先分页再加载标题，不使用旧全库候选 SQL 构造列表。返回状态计数、分页行、next check、attempts 和脱敏原因；没有逐项修改动作。web/src/api/tasks.ts 复用现有请求方式。

用户已批准事务内 PostgreSQL 触发器登记。触发器仅记录目标变更，后台通过持久游标逐层展开；覆盖 ORM、raw SQL 与批量写入，不在触发器内执行网络或全量后代扫描。

沿用 MetadataRepository、ScraperService、SchedulerService 和 TaskExecution 日志。新增季集专用状态，以 metadata_id 唯一，保存 revision、due_at、attempts、lease_token、lease_until；完成状态不纳入到期索引。TaskExecution 不是恢复依据。通过数据库触发器登记，不引入全局 GORM 回调。

## Claim and completion

短事务 FOR UPDATE SKIP LOCKED 领取，数量不超过空闲 worker；不提前领取 200 项长期排队。租约使用数据库时间，网络请求在事务外，续租失败停止处理。完成与结果保存必须验证 token/租约及目标并发版本，不能让迟到任务覆盖用户修改。处理中登记增加 revision，不清除租约；版本改变则保留待办。业务 checked_at 决定网络冷却，事件登记不能绕过。自身补全最多引起再次本地核对，不形成网络循环。

## Registration coverage

由 media、metadata_items、metadata_identifiers、metadata_provider_snapshots、metadata_artworks、artwork_assets 的事务触发器覆盖 ORM/raw SQL 的绑定、删除、合并和图片选择等入口，不逐个改写调用方。整剧变更用待归并状态和持久游标分批展开，不能在用户事务里展开数万集。无关扫描时间、播放状态、演职员变化不登记；普通集资料变化不登记父季，文件/层级变化才影响父季。

## Scheduling and repair

默认关闭和现有 24 小时调度保持不变，事件不启动网络 worker；到期仅意味着下一次手动/定时运行可领取。成功仍缺资料维持 72 小时；失败从 5 分钟指数退避至 24 小时，实际执行仍受既有调度控制。无效标识阻塞，无文件或完整结束活动待办。

首次初始化在任务执行时分批扫描文件并解析季/集，游标与登记同事务；完成后每 7 天允许一轮补偿核对。关闭期间不执行网络或核对。补偿先在批内验证完整性，不无条件唤醒完成项，不能缩短已有冷却或修改租约。删除/重绑发生在游标之前由事件捕获。

## Persistence and rollback

幂等迁移仅建表和索引，不执行全量初始化。将原分散的标识/快照/资料保存与任务确认调整为受 token 保护的事务；图片下载在事务外，选择保存需保留并发保护。状态不保存 URL/密钥/路径/完整快照。保留旧 checked_at，回退旧程序仍可使用原扫描逻辑；不同时运行两套扫描器。实际库迁移由用户部署触发。

## Risks

必须验证写入口遗漏、并发事件丢失、租约迟到写入、补全自身循环和后代展开。初始化/补偿仍有与数据量相关的成本，不能承诺总工作量恒定或网络请求恰好一次。

## 404 清理扩展方案（已批准）

真实详情 404 保存 not_found 与三天后的 due_at，仍由下次任务运行领取。仅记录请求身份用于归并时判断：身份变化、无文件或资料完整唤醒本地核对；普通资料、图片事件保留冷却。历史 retry 不反向解析。人工清理入口是原只读约束唯一已批准的例外。

详情请求使用已有 TMDb 类型化 HTTP 错误识别 404，仅请求该季/集详情返回 404 时分类，不把图片下载错误归类为集不存在。状态持久化、筛选、数量与到期领取保持一致，不使用旧日志反向构建业务状态。日志加入候选自身的剧名与季集坐标，防止裸 UUID 无法定位。

Web 待办增加“上游未找到”筛选和按需文件列表，具体 media ID 通过服务端关联查询解析；季任务列出其实际关联媒体而不是任意选一个代表直接删除。关联列表服务端分页，不全量展开大季。文件选择之后复用现有 STRM 目标解析与删除确认框，不直接信任客户端传入的绝对路径。

关键字仅在用户提交搜索时传到现有分页接口并在分页前过滤；空关键字保持原查询边界。任务中心进入时分别复用两个列表接口以 page_size=1 读取数量，关闭弹窗后刷新，不接入三秒快照轮询。季/集提示排除 done，非零按钮使用设计系统金色提醒并显示封顶数量。

删除范围完全沿用已有 STRM 本地目标语义：仅不可恢复删除明确显示的本地目标/父目录全部内容，保留 sidecar 和业务记录；未知远端目标不支持。确认后的实际操作仍由已有服务重新校验目标与允许根。不得把共享元数据 ID 当成媒体文件 ID，不因 HTTP 404 自动删除任何数据。
