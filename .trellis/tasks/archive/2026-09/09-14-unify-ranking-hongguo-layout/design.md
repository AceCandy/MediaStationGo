# 统一榜单与红果页面布局设计

## Boundaries

改动只落在发现页和任务页现有 React 组件中。通过删除冗余 JSX、清理因此失效的局部状态/处理函数，并统一已有 Tailwind 栅格类完成，不引入新组件或样式规则。

## Component Changes

- `TasksPage.tsx`：移除红果 Tab 顶部两个按钮、取消按钮专属处理函数及由此失效的 import。
- `DiscoverPageSections.tsx`：将榜单工具栏左对齐；加载骨架移除标题并固定为五列上限。
- `DiscoverContentRow.tsx`：内容行移除重复标题；实际内容和其骨架固定为五列上限。
- `HongGuoPage.tsx`：移除页头及资料管理区和由此失效的局部代码；保留详情管理能力；目录栅格固定为五列上限；榜单模式只保留数量而不重复榜单名。

## Compatibility

- 不改变路由、查询参数、权限判断、API 请求和本地缓存。
- `md` 以下沿用现有三列/四列断点，避免窄屏强制五列。
- 删除的是入口展示而非后端能力，回滚只需恢复对应 JSX 与局部处理代码。

## Risks

- 删除资料管理区后可能产生未使用 import、状态、effect 或局部组件，需结合 lint 清理。
- 标题删除后内容区间距可能变化，需检查实际内容和骨架首行对齐。
