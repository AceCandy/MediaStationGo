# 统一榜单与红果页面布局

## Goal

精简任务中心与发现页的重复控件，使 TMDB/豆瓣/Bangumi 和红果短剧目录在相同视口下呈现一致、规整的五列海报布局。

## Background

- TMDB/豆瓣/Bangumi 已通过下拉框明确显示当前榜单，内容区再次显示同名标题属于重复信息。
- 红果短剧发现页顶部的标题说明、任务中心入口和资料管理折叠区占用较多空间，与另一套发现页布局不一致。
- 两套发现页当前共用相同的响应式栅格断点，但桌面端会扩展到七列或八列。

## Requirements

- 删除任务中心红果 Tab 顶部的“取消所有红果任务”和“查看红果待匹配文件”按钮；保留每项任务已有的执行、设置和日志操作。
- TMDB/豆瓣/Bangumi 发现页的榜单选择器与刷新按钮整体左对齐。
- 删除 TMDB/豆瓣/Bangumi 内容区及加载骨架中与选择器重复的榜单标题。
- TMDB/豆瓣/Bangumi 和红果短剧目录使用同一响应式海报栅格：基础三列、`sm` 四列、`md` 及以上五列。
- 删除红果短剧发现页顶部标题说明、管理员任务中心入口和“资料管理”折叠区。
- 保留红果短剧的分类/榜单切换、筛选、搜索、目录刷新、触底加载、作品详情及详情内管理员刷新能力。
- 红果榜单模式不再重复显示已由下拉框表达的榜单名称；分类模式仍显示当前分类摘要，列表数量继续可见。
- 仅调整 Web 展示，不删除或改变红果任务、管理 API、路由、权限和查询参数行为。

## Acceptance Criteria

- [ ] 红果任务 Tab 顶部不再出现两个批量按钮，任务列表及单项操作仍正常显示。
- [ ] TMDB/豆瓣/Bangumi 的榜单下拉框位于工具栏最左侧，内容区不再重复显示当前榜单标题。
- [ ] TMDB/豆瓣/Bangumi 与红果目录在宽度达到 `md` 时每行均为五张海报，小屏仍按现有断点降为四列或三列。
- [ ] 红果发现页不再显示顶部标题说明、任务中心按钮或资料管理折叠区。
- [ ] 红果分类/榜单、搜索、刷新、触底加载、详情进入/返回及详情内管理员刷新保持可用。
- [ ] 榜单加载骨架与实际内容使用一致列数，页面无新增横向溢出。
- [ ] Web lint、build、红果发现静态检查及 `git diff --check` 通过。

## Out of Scope

- 不删除后端红果取消、启停或按 ID 刷新的能力。
- 不调整海报卡片内容、尺寸比例、详情页数据或发现接口。
- 不重构发现页组件体系，不新增依赖或通用布局抽象。

## Technical Notes

- 复用现有 `Select`、按钮样式和 Tailwind 响应式类。
- 保持发现页请求取消、缓存、稳定海报 URL 和 URL 查询状态契约不变。
