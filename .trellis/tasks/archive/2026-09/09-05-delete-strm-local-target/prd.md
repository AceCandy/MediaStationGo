# 删除 STRM 本地目标

## Goal

在媒体详情页让管理员安全删除当前选中 `.strm` 版本实际指向或经“提取轨道路径映射”解析得到的本地文件，并可选择改为删除该文件的父目录。

## Background

- 详情页已通过 `GET /api/media/:id/strm-target` 独立实时读取并显示 `.strm` 内容，不随通用详情响应返回。
- `.strm` 内容可能是本地绝对媒体路径，也可能是 HTTP/HTTPS URL。
- `ffprobe.path_mappings` 已提供 URL 前缀到本地绝对路径的映射，并包含最长前缀匹配及目录越界防护。
- 现有文件管理删除能力只信任文件管理允许根，不会自动信任路径映射的本地前缀。

## Requirements

- 仅管理员在详情页看到 STRM 目标后的删除按钮；服务端删除接口也必须要求管理员权限。
- 点击删除按钮后，服务端按具体 Media ID 实时重新读取 `.strm` 内容，不接受客户端提交的文件路径。
- 本地 STRM 目标仅在目标是存在的普通文件且位于文件管理允许根内时可删除。
- HTTP/HTTPS STRM 目标先应用当前 `ffprobe.path_mappings`：
  - 未映射、映射后仍非本地绝对路径或目标文件不存在时不可删除。
  - 映射为存在的本地普通文件时可删除；配置中的本地映射前缀是该目标的可信删除根。
- 可删除时弹出二次确认，展示“最终将删除的本地绝对路径”。
- 弹窗包含“删除父目录”复选框：
  - 未勾选时展示并删除目标文件。
  - 勾选后展示路径立即切换为目标文件的父目录，确认后递归删除该父目录。
- 删除前服务端必须再次解析当前 `.strm` 内容、当前映射和磁盘状态，并按本次 `delete_parent` 重新计算最终路径。
- 禁止删除文件系统根、文件管理允许根本身或映射本地前缀本身；最终目标不得越出对应可信根。
- 删除成功后只刷新/清空该 STRM 删除状态，不删除 `.strm` 文件，也不删除或修改 Media 数据库记录。

## Acceptance Criteria

- [x] 管理员查看本地 STRM 目标且目标文件存在时可打开确认弹窗；非管理员无删除入口且不能调用删除接口。
- [x] HTTP/HTTPS 目标在没有可用本地映射时不可删除；映射到存在的本地普通文件时可删除。
- [x] 弹窗默认显示目标文件绝对路径；勾选“删除父目录”后立即显示父目录绝对路径，取消勾选后恢复文件路径。
- [x] 确认删除文件时只有解析后的目标文件消失；`.strm` 文件和 Media 数据库记录保留。
- [x] 确认删除父目录时该目录被递归删除；`.strm` 文件和 Media 数据库记录保留。
- [x] 客户端无法指定任意删除路径，且可信根本身、越界路径、符号链接逃逸或删除前状态变化均不会导致越界删除。
- [x] 相关 Go 测试、Web lint/build 与 `git diff --check` 通过。

## Out of Scope

- 删除 `.strm` 文件。
- 删除或更新 Media、STRM 数据库记录。
- 扫描媒体库、清理失效记录或自动刷新其他页面数据。
- 为普通用户授予文件删除权限。
