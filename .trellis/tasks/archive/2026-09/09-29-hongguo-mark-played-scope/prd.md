# 修复红果批量已观看超时

## Goal

将红果合集及季的已观看操作限定到目标可见分集并批量写入，保留事务与权限语义。

## Requirements

- 红果整季或合集标记已观看、取消已观看只影响当前用户可见且有文件的分集。
- 多版本去重，沿用源作品及源集号状态身份；季操作不影响其他季。
- 全部写入保持原子性，不新增或删除播放事件，不修改收藏。
- 成功后列表与详情状态一致，新加入的分集仍未观看。
- 不更改生产观看记录，不部署，不改变 HTTP 接口或数据库结构。

## Acceptance Criteria

- [x] 528 集、多版本、隐藏库、锁定空权限、其他用户及无文件分集回归通过。
- [x] 标记和取消的第二批失败都回滚全部写入。
- [x] 60 万绑定文件下，定位仅访问目标季或合集，不展开全库展示节点。
- [x] HTTP 标记及取消返回正确 UserData，成功刷新缓存。
- [x] 独立复核、相关 PostgreSQL 回归、go vet 与格式检查通过。

## Notes

- 本记录在用户要求提交归档时补录；实现与验证已在此前完成。
- 未进行生产部署、YAMBy 实机或并发压力验收，测试耗时不等于线上端到端耗时。
