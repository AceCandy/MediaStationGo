# 系统设置子标签与同季观看自动补标

## Goal

合并系统设置导航并新增默认关闭的同季前集自动已看选项

## Requirements

- 管理导航合并为“系统设置”，保留常规、播放与探测、识别词、内容访问子标签，新增播放设置子标签；旧链接保持可用。
- 新选项默认关闭。启用后自动播放完成一集，补标当前用户同季此前未观看的可见、有文件分集。
- 使用现有完成判定；覆盖 Web 和 Emby、普通资料与红果独立资料。不跨季、不影响其他用户、已完成记录或真实播放事件。
- 保存开关本身不追溯历史；手动标记已看不触发自动补标。

## Background

- SettingsPage 和 appRoutes 当前按四个独立设置入口展示。
- PlaybackService.RecordProgress 与 EmbyService.RecordProgress 分别写普通历史；红果使用独立用户状态。
- 用户已在方案说明后回复 ok，批准建立任务并继续实现。

## Acceptance Criteria

- [x] 侧栏仅一个系统设置入口；子标签切换、直接访问及未保存设置正常。
- [x] 开关可保存、重新读取，缺失时关闭。
- [x] 未看完或关闭时不补标；开启且看完时仅补标当前季前面未完成集。
- [x] 重复回报、版本重复、隐藏媒体、缺文件、其他季和用户、红果身份均隔离；补标失败事务回滚。
- [x] 针对性 PostgreSQL 测试、Web lint/build、响应式页面验证及独立复核完成，未执行项明确记录。

## Out of Scope

不批量追溯旧观看记录，不改完成阈值，不自动跨季标记，不增加依赖。
