# 参数化图片与 WebP 缓存

用户已在本会话确认实施，明确暂不自动清理。

## 目标与范围
- Web 与 Emby 图片按宽高、质量、格式生成缓存变体，未传处理参数保持原图。
- 默认 WebP，显式 JPEG/PNG 尊重客户端；原图不覆盖。
- 变体位于 cache.cache_dir/image-variants，首个请求生成、后续复用。
- 参数校验、像素/并发边界、相同变体去重、原图更新失效、HEAD/304 正确。
- Web 请求稳定尺寸、Cookie 鉴权，浏览器不同变体缓存互不覆盖。
- 保留既有鉴权和缺图策略。不新增自动清理、预生成、固定尺寸服务端档位或管理面板。

## 验收
- 测试真实 WebP/JPEG/PNG、横竖比例、无放大、原图透传、缓存复用与更新。
- 本地所有图片出口和远程首次/热缓存行为一致。
- Web lint/build、参数与 SW 缓存检查通过；不依赖 CGO 或启动 FFmpeg。
