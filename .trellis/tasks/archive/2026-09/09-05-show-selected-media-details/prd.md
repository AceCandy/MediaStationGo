# 详情页显示选中媒体版本信息

## Goal

在媒体详情页直接查看当前选中媒体版本的数据库 ID 和本地文件路径，便于定位具体文件。

## Background

- 详情页已维护当前选中版本对应的完整 `Media` 对象，版本切换后会加载该版本详情。
- 现有详情响应和前端 `Media` 类型均已包含 `id`、`path`，无需修改后端接口。
- 国家/地区与语言由 `MediaDetailMetadata` 统一展示，新增信息适合放在同一区域下方。

## Requirements

- 在国家/地区与语言下方展示当前选中版本的 media ID。
- 在同一区域展示当前选中版本的本地文件路径。
- 用户切换媒体版本后，ID 和路径必须同步为新选中版本的数据。
- 沿用详情页现有视觉样式，并确保较长路径不会破坏页面布局。
- 仅展示已有数据，不新增后端字段、接口或依赖。

## Acceptance Criteria

- [x] 详情页国家/地区与语言下方可见当前版本的 media ID 和本地路径。
- [x] 切换版本后，两项内容与当前选中的 `Media.id`、`Media.path` 一致。
- [x] 长路径可以完整查看且不造成横向溢出或遮挡。
- [x] 现有国家/地区、语言和媒体轨道展示行为保持不变。

## Out of Scope

- 路径或 ID 的编辑、复制按钮、跳转及文件管理操作。
- 修改详情接口、媒体模型或数据库查询。
- 让国家/地区、语言等作品元数据随媒体版本变化。

## Notes

- 本次为轻量前端展示改动，PRD-only。
