# 资料入库与图片异步本地化分离

## Goal

复用 TMDb 图片本地化修复承接目录首次图片和头像下载，保留持久化重试与手工选择保护

## Requirements

- 作品资料补全保存资料、人物关系和快照后继续下一实体，不等待海报、背景图、剧照或头像下载。
- 首次有图下载及本地文件修复共用现有 TMDb 图片任务；显示名称为“TMDb 图片下载与修复”，原 key、设置、执行名称及历史保持兼容。
- 首次图片待办持久化，提交后自动处理，失败退避重试，重启恢复；定时开关仍控制全量巡检。
- 上游明确无图沿用现有无图/季集复查职责，不因首次下载失败重新抓取资料。
- 保留实体自有图片、原图存储、手工选择和并发保护。

## Acceptance Criteria

- [x] 图片请求阻塞或失败时，全部季集资料及目录任务仍可完成。
- [x] 图片任务使用已存快照，不重复请求 TMDb 详情；下载成功后图片可从本地读取。
- [x] 图片失败不标记图片完成；后续执行及重启能恢复，成功项不重复下载。
- [x] 手工选图、人物头像并发变化不被旧结果覆盖；取消会结束所有启动的工作。
- [x] 首次无图与下载失败分开处理，任务名称更新且历史映射不变。

## Notes

- 用户已批准资料/图片解耦，并确认复用图片本地化修复及改名方案。
- 不调整手动刷新、豆瓣补全、媒体入库刮削和季集复查原有同步语义；本次范围是作品资料补全。
