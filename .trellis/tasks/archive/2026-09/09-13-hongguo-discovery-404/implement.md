# 实施计划

1. 扩展红果图片所有者模型与兼容迁移。
   - 为作品海报补充稳定 `source_id`，事务内回填现有数据、检查冲突、建立唯一索引并替换兼容 owner 约束。
   - 验证：PostgreSQL 迁移重复执行和失败回滚；旧作品/人物图片保持可读；旧式 work-only upsert 仍被约束接受。
2. 让发现保存和详情补齐复用同一海报待办。
   - 分类页与榜单摘要按源 ID upsert 图片；详情成功后原子关联正式作品，详情地址优先。
   - 验证：空海报跳过、跨分类/榜单去重、发现不创建作品/分集、图片任务可下载摘要海报、补齐后不重复、并发旧下载不能覆盖新地址。
3. 扩展红果列表投影。
   - 在分页前合并摘要与正式作品，增加 `hydrated`，统一 count/order，并保持搜索、来源、榜单和题材过滤语义。
   - 验证：跨页不重不漏且 total 正确；重复来源只返回正式作品；默认同时间排序稳定；榜单位置正确；题材筛选不混入无标签摘要。
4. 调整 Web 卡片和详情错误状态。
   - 待补齐卡片复用现有海报组件并显示状态；卡片点击直接 toast 且不发详情请求，直接详情 404 通过 HTTP 状态显示明确空态和返回按钮，不新增错误 payload。
   - 验证：更新红果发现 mock 检查；检查窄屏与桌面卡片无布局回归。
5. 区分详情 404 的冷却和批次结果。
   - 404 冷却 72 小时并计入 deferred，不增加批次 failed；其他错误保持一小时和失败语义。
   - 验证：同批后续项继续；404-only 批次完成；混合真实错误批次失败；日志/指标区分暂缓与失败；失败行到期前不被 pending 选择、到期成功后清除；已有作品数据不变。
6. 独立复核与质量门。
   - 运行相关 Go 单元/仓储测试、PostgreSQL 测试（仅当 `MEDIASTATION_TEST_POSTGRES_DSN` 可用）、Web lint/build、发现脚本和 `git diff --check`。
   - 不执行全量无关测试；未配置的数据库或浏览器实机验证明确记录。
7. 更新红果目录隔离规范，使“仅正式作品可见”的旧契约与新的只读发现卡片边界保持一致。
