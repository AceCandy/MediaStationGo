# 网页三来源统一搜索

## Goal

将红果候选接入网页搜索，保留普通与NFO语义、权限、合集展示及统一分页

## Requirements

- 网页顶部联想、搜索页与共享的本地搜索服务均查询普通、NFO、红果三来源。
- 保留普通/NFO 的标题、原名、简介、类型匹配；红果复用已有独立标题检索。
- 三来源按逻辑作品统一排序、去重、截断并分页，保留当前最多 100 个候选的约束。
- 红果合集使用官方首季资料展示，每个结果保留一个可见文件及正确详情链接。
- 前端不能因相同目录/标题合并不同红果作品，红果电影必须进入文件详情。
- 保留库权限、隐藏库、受限空范围和现有空关键词浏览行为。

## Acceptance Criteria

- [x] 三来源混合搜索在顶部联想、分页和非分组入口均返回正确结果。
- [x] 分页顺序、总数、合集去重、电影与剧集展示正确；简介/类型命中不丢失。
- [x] 无文件、隐藏库、受限范围过滤正确；索引故障仍能回退数据库。
- [x] 定向 PostgreSQL 回归与独立复核通过，未改变 Emby 标题搜索行为。

## Notes

- 用户在诊断与修复方向说明后明确批准实施。仅接通现有搜索能力，不修改生产配置、部署服务、存储模型或发现页官网搜索。
