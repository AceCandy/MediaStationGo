# 实施计划

1. 扩展豆瓣 API 配置字段和旧库迁移。
   - 更新模型、公开视图、更新补丁、运行时解析与迁移列清单。
   - 补配置与迁移聚焦测试。
2. 扩展外部 API 豆瓣表单。
   - 增加前端类型、编辑状态、保存载荷和豆瓣专用复选框。
3. 在共享图片代理实现豆瓣直连策略。
   - 注入现有 API 配置服务并识别官方/当前自定义豆瓣图片域名。
   - 开启时执行“直连 → 不限域名 curl”；关闭和非豆瓣路径保持不变。
   - 使用独立直连失败标记，并让现有清理操作同时覆盖两种标记。
4. 聚焦验证与独立复核。
   - 运行相关 Go 单元测试。
   - 运行前端类型检查或构建。
   - 运行 `go vet`、`git diff --check`，再对照 PRD 复核调用链和变更边界。

## Rollback Points

- 配置字段默认关闭，可先通过 UI 关闭行为而无需回滚数据库列。
- 图片请求改动集中在 `ImageProxy`；若聚焦测试失败，回退该策略不影响配置数据和已有成功缓存。
