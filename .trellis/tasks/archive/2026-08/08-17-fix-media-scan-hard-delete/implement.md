# 实施计划

1. 增加扫描指纹字段与迁移
   - 在 `Media` 增加独立的扫描文件大小和纳秒 mtime 字段。
   - 扩展 walker、扫描输入、现有媒体快照和 Upsert 字段映射。
   - 增加幂等迁移，永久删除历史软删除媒体。
   - 验证：PostgreSQL 迁移测试覆盖新增列、旧软删除记录清理、probe 级联和重复迁移。

2. 修正增量扫描判断
   - 使用扫描路径的大小 + 纳秒 mtime 判断文件变化，移除 `.strm` 永不跳过的特例。
   - 保留本地元数据和路径派生信息刷新判断；完全一致时在 Upsert/probe 前返回。
   - 验证：普通视频和 `.strm` 首扫新增、旧数据首次补录、二扫跳过、mtime/大小变化更新；断言跳过时 `updated_at` 与 probe 次数不变。

3. 统一媒体硬删除
   - 审计并修改扫描、手动删除、重复项、整理及 repository 的全部媒体 Delete 调用为硬删除。
   - 保留共享元数据和用户状态，验证 `media_probe_metadata` 外键级联。
   - 验证：查询 `Unscoped` 也找不到被删媒体，关联状态按 PRD 保留。

4. 移除回收站后端
   - 删除回收站 service/handler、恢复与 purge 路由、批量路由、scheduler job、task definition 和对应测试。
   - 保留单一 `DELETE /media/:id`，直接永久删除数据库记录并清缓存。
   - 验证：保留删除路由成功，所有回收站/恢复/purge 路由不存在，scheduler 不再暴露回收站任务。

5. 移除回收站前端
   - 删除回收站 API、页面、路由、旧路径重定向和导航项。
   - 将详情、电影和整剧删除入口改为 `mediaAPI.delete`，更新永久删除确认文案。
   - 验证：路由清单无回收站入口；删除仍需确认且不会声称删除磁盘文件。

6. 独立复核与质量门
   - 复查所有 `Delete(&model.Media{})` 调用，确认没有遗留软删除路径。
   - 运行相关 Go 单元/数据库测试、Web lint/build、`git diff --check`。
   - 按前端路由规范检查 390x844、768x1024、1440x900 下导航无空项或错误链接；若启动服务，验证后关闭。
   - 不运行无关全量测试；PostgreSQL DSN 不可用时明确记录未执行的集成验证。
