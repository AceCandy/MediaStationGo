# Emby Latest 默认隐藏已播放项

## Goal

让 Emby 兼容接口的“最近入库”默认只返回当前用户尚未播放完成的作品，避免 Yamby 等客户端继续展示已看内容，同时保留调用方显式查询已播放或未播放内容的能力。

## Background

- `GET /Users/{userId}/Items/Latest` 当前仅按最近入库时间、媒体库和用户可见性筛选，会包含已播放作品。
- 播放完成状态以 `playback_histories` 的作品级 `(user_id, metadata_id)` 记录为准；同一作品的多个媒体版本共享播放状态。
- 当前 `Latest` 结果使用运行时缓存，缓存身份不包含播放筛选状态。

## Requirements

1. `GET /Items/Latest`、`GET /Users/:userId/Items/Latest` 及现有大小写兼容路径默认排除当前用户已播放完成的作品。
2. 支持可选查询参数 `IsPlayed`（兼容大小写参数名）：`true` 只返回已播放完成作品，`false` 只返回未播放完成作品；未传时等同 `false`。
3. 播放状态必须按当前目标用户和作品 `metadata_id` 隔离，不能按具体媒体版本或其他用户的历史判断。
4. 电影库与剧集库均在分页和最近入库排序前应用播放状态筛选；剧集库只用符合筛选条件的分集参与 Series 归组。
5. 播放状态过滤后的结果不得因既有 `Latest` 缓存返回另一种筛选状态或过期播放状态。
6. 管理端 Emby API 目录同步记录 `IsPlayed` 参数与默认行为。

## Acceptance Criteria

- [x] 未传 `IsPlayed` 时，已完成作品不出现在 `Latest` 返回数组，未完成或没有历史的作品正常返回。
- [x] `IsPlayed=true` 只返回当前用户已完成作品；`IsPlayed=false` 与默认行为一致。
- [x] 用户 A 的完成状态不影响用户 B 的 `Latest` 结果。
- [x] 筛选在 `Limit` 前生效，不会因为先取最近 N 项再剔除已播放项而少返回可用结果。
- [x] 电影和剧集媒体库的最近入库结果均符合播放筛选语义。
- [x] 相同用户、媒体库和 Limit 下，不同 `IsPlayed` 请求不会共享错误缓存；播放状态更新后下一次过滤请求得到新结果。
- [x] 相关 Go 定向测试、前端现有最小静态检查及 `git diff --check` 通过。

## Out of Scope

- 不新增或持久化 Emby `HidePlayedInLatest` 用户偏好。
- 不增加管理端或播放器端设置页面。
- 不扩展普通 `/Items` 接口的播放状态过滤能力。
- 不改变播放完成阈值、播放历史写入规则或现有用户可见性规则。

## Risks and Deferred Items

- 该方案将“最近入库默认隐藏已播放”固定为服务端行为，不完全复刻 Emby 可按用户关闭该偏好的能力；出现明确配置需求时再单独增加用户偏好持久化。
- 为优先保证播放状态立即一致，带播放状态过滤的 `Latest` 可以绕过现有短期缓存；若后续有性能证据，再增加精确的播放状态缓存失效机制。
