# 豆瓣大图与图片域名配置

## Goal

让管理员在“外部 API → Douban”中配置可选的图片域名；豆瓣海报优先下载接口返回的大图，并对已经保存的小图提供明确、可验证且不会误覆盖非豆瓣海报的处理方式。

## Background

- 豆瓣移动详情快照同时包含 `pic.normal`（`s_ratio_poster`）、`pic.large`（`m_ratio_poster`）和 `cover.image.large.url`（常见为 `/view/photo/l/public/`，也可能为 `/view/photo/large/public/` 加查询参数）。
- 当前解析先读取 `pic`，并在对象内按 `normal → large → small → url` 取值，因此实际保存了 `s_ratio_poster` 小图；该路径不是项目拼接出来的。
- 当前豆瓣候选存在时，补齐任务不会重新下载图片；只修改新解析逻辑不会升级历史本地小图。
- “外部 API → Douban”已有加密 Cookie 配置及通用 `base_url` 契约；当前豆瓣请求只使用 Cookie，未使用 `base_url`。
- 图片存储会校验真实图片内容，单文件上限 32 MiB，并按内容 SHA-256 保存；约 1066×1600 的常规豆瓣大图不会触及该上限。
- 现场只读审计确认已有 714 条豆瓣海报候选：全部为 `s_ratio_poster`、宽度不超过 300，且 714 个本地文件均存在；对应 714 份豆瓣快照均包含 `cover.image.large.url`。
- 714 条豆瓣候选中只有 1 条同时是当前海报；其余 713 条作品已有其他当前海报，历史升级不得改变这些选择。

## Requirements

1. “外部 API → Douban”支持填写可选图片域名，初始目标值为 `http://db-pic1.acecandy.cn/`；配置保存后无需重启即可影响后续豆瓣图片下载。
2. 未配置图片域名时继续使用豆瓣返回的原始图片域名，不改变现有兼容行为。
3. 配置图片域名时，只允许 `http`/`https` 绝对地址；替换图片 URL 的 scheme/host，图片资源路径保持可预测且不得影响豆瓣 JSON API 请求、Cookie 或其他 provider 图片。
4. 新豆瓣海报优先使用 `cover.image.large.url`；缺失或无效时依次回退到 `pic.large`、`pic.normal` 及现有兼容字段。
5. 不通过字符串盲猜大图地址作为新数据的首选来源；优先使用豆瓣快照已经返回的尺寸化 URL。历史数据若需要升级，可在已知 `/view/photo/<variant>/public/<photo>.jpg` 结构上派生 `/view/photo/l/public/<photo>.jpg`，但必须保留下载失败回退。
6. 大图下载成功后沿用现有内容校验、SHA-256 去重、候选关联和“无当前海报才提升”的语义；不得覆盖手工、本地或其他 provider 的当前海报。
7. 历史升级不得在下载成功前修改数据库引用；失败时保留原候选和原本地文件。
8. 不新增第三方依赖，不新增只服务单一字段的配置表。
9. 任务中心新增管理员手动触发的“豆瓣图片本地化修复”，复用现有 TMDb 图片本地化修复的任务进度、失败记录和并发保护模式；保存图片域名配置时不得隐式启动批量下载。
10. 修复任务以豆瓣候选和 provider 快照为准：本地资产文件缺失、来源为 `s_ratio_poster` 或资产宽度不超过 300 时重新下载大图；若候选同时是当前海报，仅在当前选择仍指向同一旧资产时同步切换到新资产，无需管理员手动删除小图。
11. 修复任务不得改变其他 provider、手工或本地当前海报；旧资产文件和数据库行在本任务中不自动删除，保留回滚能力。

## Acceptance Criteria

- [ ] Douban 图片域名留空时，新海报继续使用豆瓣原始域名。
- [ ] 配置 `http://db-pic1.acecandy.cn/` 后，新豆瓣图片 URL 只替换 scheme/host，并使用配置值下载。
- [ ] 非法或非 HTTP(S) 图片域名不能进入生效配置。
- [ ] 有 `cover.image.large.url` 时保存该大图；没有时按明确顺序回退，且测试覆盖对象型 `pic`。
- [ ] 大图保存后数据库资产尺寸、SHA-256 和本地文件一致。
- [ ] 既有当前海报不被豆瓣候选替换。
- [ ] 历史升级下载失败时，原候选、原当前海报和原本地文件仍可用。
- [ ] 任务中心可手动运行“豆瓣图片本地化修复”，配置保存本身不触发下载。
- [ ] 豆瓣候选本地文件缺失、来源为 `s_ratio_poster` 或宽度不超过 300 时，修复任务从已有快照选择大图、应用配置域名、校验并保存后再原子切换候选引用。
- [ ] 当前选择不是该豆瓣候选时保持不变；当前选择正是该候选时随候选安全切换。
- [ ] 聚焦后端测试、前端验证和 `git diff --check` 通过。

## Out of Scope

- 为其他 provider 增加通用图片 CDN 路由系统。
- 自动探测最快图片域名或维护按域名线路健康状态。
- 图片二次缩放、压缩或生成多尺寸缩略图。

## Technical Notes

- 这是跨后端配置、前端编辑、豆瓣解析、图片持久化和历史数据处理的复杂任务；规划完成前需要 `design.md` 与 `implement.md`。
