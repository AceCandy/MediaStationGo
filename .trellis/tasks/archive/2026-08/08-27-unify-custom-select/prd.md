# 统一自定义下拉框

## Goal

消除 Web 产品界面中的浏览器原生下拉弹层，使任务周期弹窗及其他同类字段统一使用项目主题化下拉交互。

## Background

- `web/src/pages/TasksPage.tsx:276` 的任务周期“单位”字段直接使用原生 `<select>`，对应用户截图。
- `web/src` 中共发现 29 个原生 `<select>`，分布于 17 个产品代码文件；测试和示例中未发现同类实例。
- 项目当前没有通用自定义 Select 组件；`web/src/pages/MediaDetailTracks.tsx:105` 仅有页面私有的 `<details>` 下拉实现。
- 项目未安装下拉组件库，因此不新增依赖。

## Requirements

1. 提供一个最小共享 Select 组件，使用项目现有主题变量和视觉语言，不触发浏览器原生下拉弹层。
2. 替换 `web/src` 产品代码中现有的 29 个原生 `<select>`，包括 `TasksPage.tsx:276` 的任务周期单位字段。
3. 保留每个字段原有的选项、当前值、变更回调、禁用状态、表单名称和现有布局类语义。
4. 下拉支持鼠标选择、键盘打开/导航/选择/关闭、焦点回归及点击外部关闭；暴露明确的可访问名称和选中状态。
5. 复用共享组件，不复制页面私有下拉逻辑。

## Acceptance Criteria

- [x] 任务周期弹窗“单位”字段显示主题化自定义菜单，不再出现浏览器原生下拉弹层。
- [x] `web/src` 产品代码中不存在原生 `<select>` 实例。
- [x] 所有替换字段仍能选择原有选项并触发原有业务更新，禁用态不可操作。
- [x] 键盘可完成打开、上下移动、确认和 Escape 关闭，关闭后焦点行为正确。
- [x] 下拉菜单在深色、浅色主题中使用现有设计令牌，并保持现有页面布局。
- [x] Web lint、build 与 `git diff --check` 通过。

## Out of Scope

- 不修改复选框、输入框、折叠菜单或媒体轨道私有选择器。
- 不修改后端接口、数据模型或业务校验。
- 不引入第三方下拉组件库，也不顺带重构相关页面。
