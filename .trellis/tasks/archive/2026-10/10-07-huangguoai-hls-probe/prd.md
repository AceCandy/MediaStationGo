# 修复黄果 AI HLS 合并探测失败

## Goal

增大本地 HLS 合并探测范围，诊断时长差异并保留安全错误分类，验证现有完整性校验。

## Requirements

- HLS 本地合并应能识别延迟出现的视频轨道参数，继续使用无损封装。
- 合并失败应提供固定、可诊断的错误原因，不能泄露源标题、路径、地址或密钥。
- 保留完整分片下载、完整解码和无覆盖发布；黄果 AI HLS 按视频轨道时长核对清单，允许前置音频导致总时长较长。
- 直连 MP4 及其他来源继续按总时长校验；HLS 校验策略需跨校验任务领取和服务重启保持。

## Acceptance Criteria

- [x] 合成延迟视频轨道在默认探测下失败，修改后的 Download 可以识别并合并。
- [x] 命令错误诊断覆盖尺寸缺失、存储、权限及未知错误，私密文本不进入返回错误。
- [x] 真实第 1 集通过修改后的下载客户端合并，记录视频及总时长与完整解码结果。
- [x] 不改共享校验阈值，不截断音视频；运行针对性测试并独立复核 diff。
- [x] 黄果 AI HLS 的延迟画面源保留全部音频并通过校验、发布；错误视频时长及解码失败仍拒绝发布。
- [x] HLS 标记持久化并在独立校验领取后生效，直连 MP4 与其他来源不受影响。
