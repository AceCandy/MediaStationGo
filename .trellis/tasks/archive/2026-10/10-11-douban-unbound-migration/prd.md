# 豆瓣历史资料独立迁移

## Goal

修正旧豆瓣快照迁移对媒体关联的依赖，按快照真实身份迁入共享资料中心

## Requirements

- 豆瓣资料按快照自身的真实 ID 和类型迁入中心，不以当前媒体关联为前提。
- 支持根层、subject/data 包装和数值 ID；身份缺失时仅允许唯一合法旧关联兜底。
- 明确的多层身份冲突、零/无效 ID、无身份且无关联的记录不伪造身份，不删除。
- 完整资料优先于降级、摘要，同质量取最新获取时间；无效候选不能遮挡有效候选。
- 已有共享资料不覆盖，旧快照及媒体绑定不改变，重复执行幂等，按稳定游标分批读取。
- 仅修复迁移及其测试、规范；真实运行数据库保持只读，不自动重启或清理旧行。

## Acceptance Criteria

- [x] 无豆瓣关联、改绑和类型不一致的有效快照按真实身份入库。
- [x] 根层/包装身份、数值及前导零 ID、唯一关联兜底正确；冲突及不可识别记录跳过。
- [x] 质量/时间优先、既有共享行保护、绑定和旧行不变、幂等均通过真实 PostgreSQL 回归。
- [x] 超过 1000 条及无效候选位于分页边界时仍完整迁入。
- [x] 独立只读复核通过；测试容器关闭，无生产写入。
