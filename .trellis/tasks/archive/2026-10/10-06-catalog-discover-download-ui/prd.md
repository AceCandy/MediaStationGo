# 红果与黄果发现及下载空间优化

## 范围与完成情况
- 红果分类发现与排行榜刷新拆分为独立任务，独立调度、取消与执行记录。
- 两来源下载空间支持标题或作品 ID 搜索，与状态筛选交集，筛选先于分页。
- 下载空间压缩工具栏，移除重复标题和黄果来源状态、入库提示。
- 黄果作品详情仅展示作品资料与下载操作，移除本地文件和已确认分集等内容。
- 无本地文件的媒体接口返回空数组；红果无演职员时隐藏演职员区域。
- 两来源榜单取消分页，每次下滑追加 10 部，排名连续；红果榜单取消多选。

## 验证
- 前端 lint、TypeScript 与生产构建通过。
- 合成 API 浏览器回归通过：榜单下滑、重试、切榜隔离、刷新、旧页链接规范化、详情返回、分类与搜索、红果分类多选、暗亮主题和手机桌面布局。
- 前序下载空间浏览器回归与针对性数据库测试通过；空媒体页 HTTP 回归通过。
- 修改后已独立复核，调试服务关闭，临时截图与测试数据库已清理。

## 验证边界与剩余问题
- 本轮浏览器验证使用合成 API，未联调真实来源网站。
- 红果下载作品查询性能检查在本机 PostgreSQL 16 环境未通过；使用原始 HEAD 查询复测存在同样的分集全表扫描，为既有问题，未扩大范围修复。
- 其他并行 Emby/NFO 任务保持未提交，不纳入本任务。
