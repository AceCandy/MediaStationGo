# 媒体数量统计优化

## 目标与范围

解决 GET /Items/Counts 完整目录聚合造成的长耗时，按用户可见媒体库统计普通、NFO、红果和黄果 AI 来源。仅修改此接口的计数实现、回归测试、接口说明与规范；不修改列表、收藏、播放状态、数据库结构或运行服务。

## 用户确认的计数口径

- MovieCount：电影作品记录数，多版本和分段不增加作品数。
- SeriesCount：剧集作品记录数，红果不合并官方合集 group。
- EpisodeCount：全部可见 media 文件行数，包含电影、未绑定文件、多版本和分段。
- ItemCount：MovieCount + SeriesCount，即作品总数；不得混入文件数。
- 所有统计保留可见媒体库筛选，无文件的作品不计入。

## 验收条件

- [x] 四套体系作品计数不展开完整目录、图片、收藏或播放状态。
- [x] 四条作品聚合及一条文件计数并发执行，历史未初始化归属保留可见文件存在性检查。
- [x] 多版本、分段、跨库共享作品、红果同合集多个作品、无文件及未绑定记录符合口径。
- [x] 媒体库权限交集、隐藏库、锁空权限和历史 NULL 归属通过回归。
- [x] 取消请求、任一来源查询失败不返回部分成功计数。
- [x] 接口说明、示例和规范与最终字段语义一致。
