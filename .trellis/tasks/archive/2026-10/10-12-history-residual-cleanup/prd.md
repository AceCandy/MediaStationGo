# 清除架构复审确认的历史残留

## Goal

删除媒体库旧结构回退、旧Vue接口与孤立SSE票据、重复调度别名和旧哈希深链；只读核实红果一次性历史整理工具状态，验证现行目录与任务链接。

## Requirements

- 用户已批准实施架构复审中的四类残留清理；无需支持旧版数据库、旧 Vue 界面或旧哈希深链。
- 媒体库目录操作只依赖当前 roots 表，不静默退化或在读取时从 Path 补建数据；保持新建、多路径、扫描及主目录投影。
- 移除旧 Vue 配置/schema/事件票据接口和未接入当前事件流的两套票据实现，保持现行设置与事件广播。
- 移除无当前 Web 调用的调度别名，保持任务中心及整理设置使用的管理接口。
- 退役旧哈希剧集链接解析，保持普通/NFO/红果/黄果的当前作品链接及分页。
- 核实红果一次性历史整理工具是否还有可处理数据；确认完成后移除工具和专属实现，保留当前目录扫描工具。
- 不改业务数据、不执行生产 SQL 写入、不重启用户服务；用户后续已授权将本轮工作提交到 main 并归档，不推送远端。原有 core 保持未跟踪。

## Acceptance Criteria

- [x] 缺少 roots 表时相关读写返回数据库错误；当前多路径创建、修改和扫描回归通过。
- [x] 旧 Vue/调度别名不再注册；当前管理设置、任务触发与事件流仍有有效入口。
- [x] 当前剧集身份链接可读取作品和季集；旧哈希输入不触发整库身份扫描。
- [x] 历史整理候选为零后删除其 CLI、仓库方法和专属测试，现行下载摘要功能不受影响。
- [x] 全包编译、受影响的真实隔离 PostgreSQL 测试、相关 Web 检查和独立只读复核通过；跳过不计通过。
- [x] 规范与审查记录同步，临时测试服务和产物在结束前清理。
