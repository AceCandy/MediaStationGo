# 设计

持久字段 UseOriginalVideoID（默认 false）记录该次尝试的用户选择，并在详情中显示。新增单集 action retry-original，只接受 failed 且原视频 ID 有效的任务，事务内复用原有分集存在性与重试重置逻辑后设置 true。普通单集/作品重试重置为 false。

执行阶段在新传输前按模式分支：默认核验详情；手动模式直接验证并使用原 ID 取流。原始文件和散列检查点仍优先恢复。复用现有来源次数上限、文件校验和非覆盖发布。

失败集详情增加按钮，复用 confirmAction 明确原集号/视频和剧情顺序限制。扩展 API action 类型，不传视频 ID、地址或密钥。仅增加模型字段，通过既有 AutoMigrate 生效，无共享元数据修改。

其他正常任务触发分集清理时，保留手动原 ID 选择：有手动选择的整部重排不得重建队列，尾集/空位调整不删除手动任务；确认整部下架仍遵守原清理规则。
