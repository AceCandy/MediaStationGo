# 修复目录删除监听的误告警与重试

## 目标

正常删除子目录后成功排队核验旧媒体记录即结束目录处理，避免不存在路径的误告警及重试；保留根目录离线保护和核验失败重试。

## 范围

- 仅修改目录事件处理及对应回归测试，复用既有媒体删除核验边界。
- 不改数据库结构、不部署或重启运行中的服务。

## 验收结果

- [x] 正常删除子目录后，旧媒体记录排队核验，消失文件的记录正常删除。
- [x] 成功排队且对应根目录可访问时，不再对旧目录报警或重试。
- [x] 根目录离线时保留媒体记录及目录恢复重试；核验查询失败仍重试。
- [x] 可访问根目录必须包含当前事件路径，避免回退到其他根目录时误终止重试。
