# 实现与复核

## 根因与修复
- Boot 同时启动离线迁移与自动回填；改为后台迁移成功后才启动回填，失败/取消直接退出，日志使用现有脱敏。
- 来源正文按组件和语言分开，作品关系不按语言分开；共享关系写入方法在同一事务锁内检查同属主、主要语言、较新有效数组。演员/幕后独立保护，较新空数组有效；新基础正文无列表不构成阻挡。
- 不新增表或配置，不删除旧数据，不修改生产任务状态。

## 独立复核
只读探子核验启动顺序、SQL 与季集路径。SQL OR 分组疑虑通过真实数据库测试核验（当前正文若绕过时间条件，所有正常关系都会被阻挡），另显式加外围括号保证可读性。季接口保存 season_episode 子正文，测试覆盖新季阻挡旧单集以及新单集阻挡旧季。相等来源时间延续原有可替换行为，本轮仅防止来源时间倒退。

## 验证
原代码已复现跨语言旧 detail 清除新关系、部分列表覆盖有效空演员列表。新增测试覆盖 detail、独立 credits、有效空列表、分组缺项、新 base 无列表、次要语言、较新正常更新、人物作品、季集双向保护，以及启动迁移阻塞/成功/失败/取消。

未进行生产 TMDb API 联调、全包回归，也未核验或修复生产库可能已被旧版本覆盖的关系。修复通过验证后按用户要求提交归档。

最终结果：隔离 PostgreSQL 下来源中心/启动/快照回填专项 `go test -race` 全部通过（repository 22.387s，service 29.025s）；`go vet ./internal/repository ./internal/service` 与 `git diff --check` 通过。临时 PostgreSQL 与本轮日志在结束前清理。
