# 统一收藏默认排序

## 目标
网页及 Emby 各资料来源的收藏默认按添加收藏时间倒序，最近添加的在最前。

## 约束
- 保留客户端明确指定的原有排序规则。
- 播放进度及重复设置收藏不得改变添加时间；取消后重新收藏使用新时间。
- 用户确认旧 NFO 没有收藏，不回填或伪造历史收藏时间。
- 保留类型、权限、来源身份、计数及分页语义，不因重复收藏行增加作品数量。

## 验收
- [x] 普通媒体、NFO、红果、黄果 AI 的 Emby 全局及库内收藏默认倒序。
- [x] 网页合并普通媒体与 NFO 收藏时按统一时间排序。
- [x] 重新收藏、重复收藏及 NFO 播放更新符合时间约束。
- [x] 分页与计数回归通过，重复记录不会放大普通剧集候选。
- [x] 原有显式名称排序保持有效。
