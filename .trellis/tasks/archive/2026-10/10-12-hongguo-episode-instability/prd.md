# 隔离红果异常分集映射

## 需求
- 上游部分分集换位时，映射一致的分集继续下载，异常只阻止对应分集。
- 异常分集标记集号待确认，保留原任务视频 ID；手动重试不能静默换成其他视频。
- 已完成文件和恢复检查点保留，整部下架及有明确证据的尾集/空位清理保持原有保护。

## 验收
- 模拟部分分集连续换位，正常集成功、异常集失败且原任务及 ID 保留。
- 验证首次请求命中旧顺序而复核换位、两次稳定换位、无视频 ID 的旧任务初始化。
- 重试及来源切换不修改有效视频 ID；不影响下架、尾集清理、已完成文件。
- 修改后执行针对性的 Go 测试并独立复核，不触及生产下载队列。

## 实现与验证结果
- 按当前集核验两份列表，其他分集变化不阻塞正常集；已有有效视频 ID 不被重试或换源覆盖。
- 同集数局部换位保留整部任务，受影响集使用现有失败状态提示集号待确认，不进入来源自动重试。
- 完成独立只读审查及主线程复核；加强隔离测试，覆盖实际模拟传输和已完成文件内容保护。
- 红果针对性回归 12 个测试函数通过（53.872s）；加强测试后的核心 6 个测试函数通过（21.827s），覆盖局部变化、下架复核、身份保护、并发清理及检查点恢复。gofmt 和 git diff --check 通过。
- 数据库测试使用随机隔离 schema 并自动清理；未操作生产下载队列、未重启服务、未执行全库测试，未验证真实剧情顺序。
