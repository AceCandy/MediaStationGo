# 调整媒体库扫描入口与自动触发

## Goal

统一手动媒体库扫描入口，并在新增媒体库或新增路径后自动触发最小范围扫描，减少重复操作和无目标的全库扫描。

## Confirmed Facts

- 当前任务面板的“媒体库扫描”手动执行时，会扫描全部已启用媒体库。
- 当前媒体库管理弹窗提供整库和单路径扫描入口，媒体库详情页另有“立即扫描”入口。
- 新建媒体库或新增路径保存成功后，当前不会自动扫描。
- 后端已经具备“扫描指定媒体库”和“扫描指定路径”的异步接口。
- 任务页面已经加载媒体库列表，任务运行请求类型也已经支持 `library_id`，但“媒体库扫描”尚未读取该参数。
- 当前新建媒体库接口在命中同名同类型媒体库时会向已有库追加路径，而不是创建重复媒体库。

## Requirements

- 任务面板的“媒体库扫描”增加媒体库选择；手动执行时，只扫描所选媒体库的全部已启用路径。
- 删除媒体库管理弹窗中的整库扫描和单路径扫描入口。
- 删除媒体库详情页中的“立即扫描”入口，使任务中心成为唯一手动扫描入口。
- 新增一个媒体库并保存成功后，自动扫描该媒体库的全部已启用路径。
- 向已有媒体库新增一个路径并保存成功后，只自动扫描这个新增路径。
- 编辑媒体库封面、已有路径名称、路径地址、启用状态或排序等已有配置时，不自动触发扫描。
- 定时“媒体库扫描”保持现有行为：扫描全部已启用媒体库。
- 扫描继续作为后台任务执行，页面关闭不应中断。
- 保存成功后的自动扫描不额外弹出成功或失败提示；用户统一在任务中心查看扫描执行情况。

## Out of Scope

- 不改变媒体文件识别、入库、轨道探测和自动刮削逻辑。
- 不增加批量选择多个媒体库或路径的能力。
- 不改变定时扫描的配置项和执行范围。

## Acceptance Criteria

- [ ] 从任务面板手动运行“媒体库扫描”前必须选择一个媒体库，任务只访问该媒体库的启用路径。
- [ ] 定时触发“媒体库扫描”仍访问全部已启用媒体库。
- [ ] 媒体库管理弹窗不再展示整库或单路径扫描按钮。
- [ ] 媒体库详情页不再展示“立即扫描”按钮或扫描进度状态。
- [ ] 新建媒体库保存成功后，自动创建该媒体库的后台扫描任务。
- [ ] 已有媒体库新增路径保存成功后，自动创建该路径的后台扫描任务，且不扫描同库其他路径。
- [ ] 编辑已有媒体库或已有路径不会触发扫描。
- [ ] 自动扫描触发后，用户能在任务面板看到运行状态和结果。
- [ ] 自动扫描的启动结果不改变保存操作的成功反馈，也不回滚已保存的媒体库或路径。
