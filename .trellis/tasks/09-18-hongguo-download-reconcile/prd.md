# 红果下载下架清理与分集变化核对

## Goal

确认下架后清理未完成下载及无本地内容的红果资料，核对分集变化并保护已下载文件

## Requirements

- 下载期间确认整部下架后，清理未完成下载；没有完成记录、可恢复下载或媒体库内容时，同时清理该作品红果资料。
- 已完成文件、已完成历史及其所需资料始终保留；网络异常、单次搜索未命中、列表不完整不能触发删除。
- 比较新旧分集，区分尾集减少、单集缺失与重新分集，避免把新旧内容按相同集号混合。
- 重新分集且尚无下载内容时按新列表重新入队；已有内容默认保留并提示人工确认，不自动覆盖完成文件。

## Acceptance Criteria

- [x] 连续明确不存在且搜索正常未命中时，清理未下载作品和对应资料。
- [x] 部分完成、暂存恢复和媒体保护有效；其他作品及用户观看记录不受影响。
- [x] 网络、解析异常和不完整分集返回不触发清理。
- [x] 完整且重复一致的尾集减少消除失效下载并校正列表汇总。
- [x] 分集变化及并发租约场景有回归测试。

## Notes

- 用户已确认上述清理规则并明确要求实施。此次不部署、不直接操作生产数据库。
