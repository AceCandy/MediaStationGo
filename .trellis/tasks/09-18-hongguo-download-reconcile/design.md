# 技术设计

在新传输读取详情的现有入口核对上游状态。两次详情 404，且标题搜索正常返回但不含目标 source ID，作为整部下架证据。其他错误保持原有失败和换源流程。

仓储事务按作品、下载行顺序加锁，重验当前租约，清理没有完成/原始文件/发布检查点的下载。保留媒体绑定、完成历史和可恢复数据依赖的资料。无上述保护时删除该 source 的发现、榜单、同步失败、固定下载位置、作品与从属资料。共享人物、用户状态、磁盘完成文件不随作品删除。

分集核对使用完整且重复一致的完结详情；视频 ID 的坐标关系用于区分仅缺集和重排。空位还需原视频两次明确下架响应。无完成或恢复内容时原位置重建队列；已有内容时保留并提示人工确认。相同集数下只有已知视频换位才认定重排，单纯 ID 轮换保持原有行为。

只修改下载服务、红果仓储及相应测试/契约，不引入新依赖。事务失败回滚数据库；不自动删除完成文件。
