# 设计

共享 MetadataRepository 的普通与允许合并入口，在事务内按规范化外部标识排序取得 PostgreSQL advisory transaction lock，再解析已有作品。唯一标识冲突不得静默改绑到新实体；明确的归并仍通过现有 mergeMetadataGraph 完成。

showDirFromEpisodePath 的季目录识别接受明确的版本后缀，保持原有特殊季和无季目录回退行为。范围限于已知媒体版本标记，不吞掉任意括号标题。

回归测试使用隔离 PostgreSQL、多条 schema 固定连接及可控并发，检查最终作品身份与标识归属；保留不同作品不互相合并、原有冲突回滚契约。

现有数据修复通过 repository.Merge 在事务内执行，操作前复核源/目标、TMDB ID、7 集/14 文件及所有引用。先在隔离数据中验证，再对指定两条资料应用；事务失败自动回滚。修复前保留临时定向备份供当次核验，成功后删除。刷新相关读取投影，确认卡片资格与用户状态。

不部署或重启现有用户服务；代码交付与运行版本状态明确说明。
