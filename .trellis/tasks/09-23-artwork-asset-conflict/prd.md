# 修复图片资产并发入库冲突

## Goal

统一图片资产唯一键冲突处理，验证并发复用及关联完整性

## Requirements

- 相同图片并发入库时复用唯一资产，各媒体保持独立图片关联。
- 普通保存、目录补图、候选图片、两种图片修复和 NFO 入库入口均遵守此行为。
- 保留图片唯一约束、已有选择保护及事务回滚语义。
- 不修改文件存储、刮削并发、数据库结构或线上数据。

## Acceptance Criteria

- [x] PostgreSQL 并发回归验证资产去重和所有关联正确。
- [x] 没有相应哈希资产的异常冲突返回错误，不产生错误关联。
- [x] 图片仓储现有测试及 Go 静态检查通过。
- [x] 完成独立审查，测试服务关闭、临时产物清理。
