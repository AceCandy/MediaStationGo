# 设计

复用 nfoViewQuery 文件/祖先可见性条件与现有独立身份。Emby 指定库作品层用轻量候选过滤、排序、分页：普通标题且无状态筛选使用 EXISTS；日期/状态参与时保留必需汇总。页内身份限定文件后复用 NFONodes 和 payload，不能只在全量节点外过滤计算身份。

特殊筛选、季集路径保留回退。Latest 使用不计总数路径，普通列表保持准确总数。NFO 库内 Latest 的 DateCreated/MIN 保持不变。

Web 候选只算身份、排序所需 MAX 时间，总数与分页共享候选；当前页再统计代表文件、集数、版本数。保留缺图/中文标题过滤，不直接拿 Web DTO 替代 Emby DTO。

普通电影库检测用 SELECT EXISTS 包装原条件的 SELECT 1。无数据库迁移，可通过代码回滚。全局混合和常规剧库优化延后。
