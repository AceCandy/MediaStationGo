# 精简豆瓣电影补齐日志

## Goal

让“豆瓣电影信息补齐”任务日志只呈现实际数据变更，便于直接看出改了哪些电影、哪些字段。

## Background

当前完成日志包含“扫描、更新、无变化、跳过、失败”等计数，即使全部为 0 也会输出；用户期望隐藏过程性或无变更统计，只关注实际新增、更新、删除及其详情。

现有任务可能填充电影元数据字段、新增豆瓣海报候选并保存豆瓣原始快照，不执行删除。当前结果只记录字段数量，未记录字段名或逐电影详情。

## Requirements

- 完成日志仅展示本次实际发生的新增和更新；当前任务没有删除行为，不虚构删除记录。
- 每项实际变更给出可识别的电影与变更详情。
- 不展示扫描、无变化、跳过统计。
- 没有实际新增或更新时，不输出全零统计，使用简短的“本次无变更”结果。
- 仅保存或刷新豆瓣原始快照不算更新，不展示。
- 失败信息继续展示，并包含可识别的电影信息。

## Acceptance Criteria

- [x] 有实际新增或更新时，完成日志包含对应非零数量和逐项详情。
- [x] 完成日志不再包含“扫描”“无变化”“跳过”字段。
- [x] 没有实际变更时，日志不出现全零计数，并明确显示“本次无变更”。
- [x] 失败信息仍可被用户看见，不因精简变更日志而丢失。
- [x] 仅保存或刷新豆瓣原始快照时，不计入更新且不生成变更详情。

## Key Decisions

- 新增豆瓣海报候选属于“新增”。
- 填充或替换电影元数据字段属于“更新”。
- 当前任务没有删除动作，因此正常日志不会出现“删除”。
- 仅保存或刷新豆瓣原始快照不属于用户可见变更，不计入“更新”。
- 复用现有任务日志的逐项详情机制，无需修改前端展示。

## Out of Scope

- 修改豆瓣补齐任务的候选筛选、请求频率或数据写入规则。
- 为满足日志分类而新增删除行为。
