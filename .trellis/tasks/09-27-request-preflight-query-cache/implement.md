## 验证方式

- 使用现有 PostgreSQL 测试 helper 和新增针对性用例，不引入测试框架。
- 测试连接通过 `MEDIASTATION_TEST_POSTGRES_DSN` 提供，使用独立测试数据库和每例随机 schema；没有 DSN 导致 Skip 不算通过。当前环境变量未配置，实施时需准备隔离 PostgreSQL；不把运行中的业务库擅自当测试库。
- 建议目标测试：`go test ./internal/repository ./internal/service ./internal/handler -run 'Test(Library|MediaVisibility|PlayProfile|AuthenticatedRoutes|PasswordChange|Profile|Emby)' -count=1`，以新增真实测试名补齐；必须检查输出中的 SKIP。
- 并发回填用屏障控制读/写顺序，不用脆弱 sleep；对相关包新增测试执行 `-race`。
- `gofmt` 仅格式化修改的 Go 文件，`git diff --check`；最终按风险执行 `go test ./...`，性能采样不与数据库回归并行。
- 临时测试服务和产物结束前清理，保留用户原有服务与数据。
