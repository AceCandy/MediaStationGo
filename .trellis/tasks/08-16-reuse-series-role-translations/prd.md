# 复用剧集角色翻译

## Goal

避免同一季的多个单集为相同角色名重复调用 AI，同时保留人物姓名按人物身份复用、角色名按作品上下文翻译的现有语义。

## Background

- 人物姓名使用内部 `Person.ID` 作为翻译缓存上下文；同一来源人物 ID 正常只翻译一次。
- 角色名当前使用所在 `MetadataItem.ID` 作为缓存上下文。单集各有独立 ID，因此同一角色在同一季的每一集都会形成独立 AI 翻译条目。
- 元数据层级固定为 `Series -> Season -> Episode`，Episode 的 `ParentID` 指向 Season。
- 已有角色翻译缓存包含上下文、原文、目标语言和提示词版本，不需要新增表或迁移。

## Requirements

- 单集角色翻译必须使用所属季 ID 作为缓存上下文，不再使用单集 ID。
- 季角色继续使用季 ID；系列角色继续使用系列 ID；电影角色继续使用电影 ID。
- 相同季、相同角色原文、相同目标语言和提示词版本必须合并为一个翻译组，并将结果写回该季所有匹配单集。
- 不改变人物姓名翻译、人物身份合并、角色原文保存及陈旧写回保护逻辑。
- 不新增数据库字段、迁移、配置项或依赖。

## Acceptance Criteria

- [x] 同一季多个单集包含相同角色原文时，只产生一个待翻译组和一次 AI 结果日志。
- [x] 同一季不同角色原文仍分别翻译。
- [x] 不同季的相同角色原文保持独立上下文，允许得到不同译文。
- [x] 电影、系列和季自身的角色缓存范围保持不变。
- [x] 人物姓名仍按 `Person.ID` 复用，不受本次修改影响。
- [x] 相关 Go 聚焦测试和 `git diff --check` 通过。

## Out of Scope

- 跨季或跨系列全局复用角色译文。
- 自动合并不同 provider 下的同一真人。
- 修改演员采集、演职员继承或任务日志展示。
- 清理已经生成的单集级历史翻译缓存。

## Risks

- 同一季中同样的角色原文将共享译文；这是本次减少重复调用的预期行为。
- 旧单集级缓存会保留但不再命中，不影响正确性，仅占用少量数据库空间。
